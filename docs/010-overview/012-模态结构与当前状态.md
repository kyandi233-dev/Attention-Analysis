# 012｜模态结构与当前状态

本文件只回答各研究模态目前处于什么状态，避免把“模块存在”误解为“当前已经运行”。

| 模态 / 层 | 当前状态 | 当前入口 | 说明 |
|---|---|---|---|
| NIR | **正式全量已完成，当前主分析模态** | `docs/020-nir/`、`runtime/nir-formal/` | 正式主链为逐帧 YOLO26n → ROI → RITnet batch inference |
| Behavior | **正式 SART 分析已形成** | `docs/030-behavior/` | 正式 SART 报告与配套资产统一挂在 behavior 模块下 |
| RGB | **接口保留，当前关闭** | `docs/040-rgb/` | 不迁移未经验证的 rPPG / HR / HRV 结论 |
| Cross-modal | **概念与接口保留，当前未作为独立运行模块** | 本文件 | 单模态测量和研究问题成熟后再建立独立融合代码/配置/文档 |
| Attention / scoring | **不把算法输出直接等同于专注真值** | 后续研究决策 | 行为、眼部指标、测量质量与最终评分模型保持分层 |

## 何时把新模块升级为独立目录

只有当一个模块至少形成独立实现或分析流程，并产生需要长期维护的多份说明文档时，才在 `docs/` 建新的编号目录。仅有一个状态说明或未来接口时，不提前创建空壳目录。
