# 011｜系统架构与数据流

## 当前状态

Attention-Analysis 已完成正式 NIR 全量分析。当前仓库工作的重点是结果复核、仓库结构维护、方法增量与可复现性，而不是“准备进入正式 NIR pipeline”。

当前正式 NIR 主链为：

```text
正式 NIR 视频
    ↓
FocusWave v3.1.3 phase windows
    ↓
逐帧 YOLO26n 眼框检测
    ↓
单眼 ROI
    ↓
RITnet batch inference
    ↓
瞳孔指标 / 失败状态 / phase 信息
    ↓
CSV / JSON / overlay 等分析输出
```

正式模式采用逐帧 YOLO。CSRT/KCF 等 ROI tracking 代码仅保留用于诊断与历史复现，不属于当前正式处理主链。

## 模块关系

```text
实验数据
├── NIR ───────→ 020-nir/
├── Behavior ──→ 030-behavior/
└── RGB ───────→ 040-rgb/（接口保留，当前关闭）

单模态输出
    ↓
未来的 cross-modal / scoring 层
（当前不作为独立已运行模块）
```

cross-modal 是未来可能执行的“多模态融合分析功能”，而 architecture 是对整个系统关系的描述；因此当前不再把二者作为两个同级 `docs` 目录。跨模态状态统一记录在 `012-模态结构与当前状态.md`，待其真正形成独立代码、配置和多份方法文档后再升级为独立模块。
