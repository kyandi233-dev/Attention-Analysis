# Overview｜项目总览

这里是 `docs/` 的第一阅读入口，回答“项目现在是什么、各模块怎么连接、关键资产在哪里”。它不重复各模块的具体算法细节，也不承担日期型工作记录的职责。

建议阅读顺序：

1. `011-系统架构与数据流.md`：当前整体分析结构。
2. `012-模态结构与当前状态.md`：NIR、Behavior、RGB 与 cross-modal 的当前边界。
3. `013-仓库资产与复现关系.md`：datasets、training、models、runtime、src、tests、artifacts 等目录之间的关系。

历史执行过程去 `../工作记录/`；具体 NIR 方法去 `../020-nir/`；行为分析去 `../030-behavior/`；技术路线变化与采纳/放弃理由去 `../050-decisions/`。
