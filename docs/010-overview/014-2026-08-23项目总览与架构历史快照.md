# 项目总览与架构

## 2026-08-23 当前状态

Attention-Analysis 已完成正式 NIR 全量分析。当前工作阶段是仓库结构整理、资产归档、可复现性维护和后续结果复核，不再处于“等待 ROI 准入 / 准备正式全量运行”阶段。

当前结构整理主线：`main`。

当前正式 NIR 链路：

```text
正式 NIR 视频
        ↓
FocusWave v3.1.3 时间轴 / phase windows
        ↓
逐帧 YOLO26n 眼框检测
        ↓
眼睛 ROI
        ↓
RITnet batch inference
        ↓
瞳孔指标 + 失败状态 + phase 信息
        ↓
CSV / JSON / overlay 等正式分析产物
```

正式模式采用逐帧 YOLO；tracking 代码继续保留用于诊断和历史复现。正式运行权重已经封装在 `runtime/nir-formal/models/` 中。

当前 NIR 运行与资产入口：[08-23 NIR正式分析当前入口与资产映射](docs/010-nir/08-23-01-NIR正式分析当前入口与资产映射.md)。

# 历史架构与决策快照

以下内容用于保留项目方法演变，不代表当前正式运行路线。更完整的过程证据以 `docs/工作记录/` 中日期型文件为准。

## 2026-08-21 历史工作阶段

> 2026-08-21 17:30（Asia/Shanghai）｜项目当时已从预实验管线审计转入正式数据分析准备阶段。

北京已完成一百多名正式被试的数据采集，当时预计 2026-08-23 晚回珠海后开始正式分析。NIR 眼框检测器正在 AMD RX 6750 GRE 12GB 电脑上使用 CPU 完成 100 epochs 训练；当时计划训练完成后将候选权重转移至 NVIDIA 电脑进行批量推理。

当时设想的正式架构为：

```text
OpenCV 读取视频
        ↓
是否需要重新检测？
   是：YOLO 检测并校正 ROI
   否：tracking 更新上一帧 ROI
        ↓
RITnet 处理眼睛 ROI
        ↓
连续性、可用性与失败状态 QC
        ↓
行为时间窗与 NIR 指标
```

这里的“是否需要重新检测”是管线控制逻辑，不是 OpenCV 自动完成的功能。当时重新检测条件、tracking 实现和 RITnet 参数尚未冻结。后续实际正式路线改为逐帧 YOLO + RITnet batch。

## 2026-08-16 历史停止门

> 当时 NIR 高严重度修复和历史复核已完成；PuReST 仍是瞳孔候选，但三种完整人脸 ROI 后端在双眼特写正式输入上均未通过身份硬门，因此生产冻结停止。

### 当时审批门

1. **骨架与小样本复核**：12帧/24眼审批包完成，现保存在 `artifacts/gate1-24eyes/`。
2. **528眼真值、阶段4/4b与5**：人工真值完成；轴角修复后六算法/18配置仍无准入者；PuReST当时保留为连续检测候选。
3. **正式ROI入围门**：sub-011 Block1 60时点复核。MediaPipe、YuNet 与当时 YOLO-face 正确双眼 ROI 均为 0/60，因此停止尺度调优和当时的生产参数冻结。
4. **行为证据与专注定义**：041–045证据、图表、修改建议和字段字典完成；专注评分未直接由算法输出冻结。

当时只有新的 ROI 候选通过正确双眼身份、≥95%人工可用率和≤2%严重裁断率后，才计划恢复 PuReST 参数冻结与完整生产输出。该停止门后来被自训练 NIR YOLO26n 眼框路线突破。

### 当时 NIR 方法结论

- 椭圆轴角修复为原始表示与 canonical 表示双轨；轴交换同步旋转 90°，mask 与光度使用原始 size/angle。
- 阶段4/4b在 `artifacts/benchmark-axis-fix-review/` 独立复跑，最佳约17.2%，当时没有算法/参数配置达到准入门槛。
- 阶段5在 `artifacts/sequence-adapter-review/` 复跑；PuReST 可见覆盖0.5230、恢复192 ms，连续性优于 PuRe，但这属于当时预实验代理标签证据。
- PuReST 使用普通连续调用 + `minPupilDiameterMM=0.5` 兼容设置 + Python 严格 px 后置门，不能描述为内部全程严格 px 控制。
- 正式 Block1 画面为双眼/鼻梁特写。MediaPipe 与 YuNet 需要完整人脸；当时 YOLO-face 会把单眼区域当脸，三者正确双眼 ROI 均为0/60。
