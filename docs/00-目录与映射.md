# 00｜文档目录与映射

> 项目文档入口。文档体系采用“双维度结构”：保留研究模态划分，同时增加方法、架构和决策层，避免工作记录与技术说明混杂。

## 文档体系

当前 docs 按以下逻辑维护：

1. 研究模态层：描述不同数据来源与分析任务。
2. 方法层：描述使用的算法、指标和技术方案。
3. 架构层：描述整个 pipeline 的组织方式。
4. 决策层：记录技术选择、舍弃方案和原因。
5. 工作记录层：保留完整实验过程与历史证据。
