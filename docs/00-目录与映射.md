# 00｜文档目录与映射

> 项目文档入口。文档体系采用“双维度结构”：保留研究模态划分，同时增加方法、架构和决策层；历史工作记录继续保留原目录和时间顺序。

## 文档体系

当前 `docs/` 按以下逻辑维护：

1. **研究模态层**：描述不同数据来源与分析任务。
2. **方法层**：描述算法、指标、参数与技术方案。
3. **架构层**：描述 pipeline 的模块关系、数据流和输入输出边界。
4. **决策层**：记录技术选择、舍弃方案和冻结理由。
5. **工作记录层**：保留完整实验过程、执行证据与历史决策。

## 当前整理原则

- 允许进行已确认的移动、重命名和索引整理。
- 不删除任何历史文件；如确需删除，先单独确认。
- 不覆盖实验结果或改变历史工作记录的原始语义。
- 当前入口文档必须反映“正式 NIR 全量分析已经完成”的项目状态，历史候选/阻断状态只能作为历史信息保留。
- 模态文档、通用方法文档和工作记录各自承担不同职责，避免重复维护同一份事实。
