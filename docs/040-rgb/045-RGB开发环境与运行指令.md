## 3. 正式单被试运行

先设置 Face ONNX 模型目录：

```powershell
$env:ATTENTION_FACE_MODEL_DIR = "D:\_AttentionData\Beijing-RGB\_test\face-directml\models\pyfeat"
```

然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_rgb_formal_subject.ps1 `
  -Subject sub-031
```

总控会自动切换所需 Conda 环境，不需要人工在阶段之间反复 activate。

正式顺序：

```text
1. Face 15 Hz frame preparation
2. Motion full-fps + Pose 10 Hz
3. Face DirectML full-span inference
4. tracking / primary / eyelid derived
5. final extraction validation
```

只有第 5 步通过后才生成：

```text
D:\_AttentionData\Beijing-RGB\sub-031\sub-031_manifest.json
```

其中 `extraction_complete=true` 才表示该被试已经完整抽取。QC 不在这里判定。

## 4. cohort 全量运行

`sub-031` 首次完整跑通后，直接运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_rgb_formal_cohort.ps1
```

cohort runner 会先重新生成 `rgb_inventory.csv`，只处理 `analysis_eligible=True` 的正式被试，然后逐人执行单被试总控。

它会自动：

```text
已有完整 manifest → skip
未完成 → run
单个被试失败 → 写入 cohort_status.csv，继续下一人
全部结束 → 写 cohort_manifest.json
```

只跑指定被试：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_rgb_formal_cohort.ps1 `
  -Subjects sub-031,sub-032,sub-033
```

进度文件：

```text
D:\_AttentionData\Beijing-RGB\cohort_status.csv
D:\_AttentionData\Beijing-RGB\cohort_manifest.json
```

`cohort_status.csv` 每完成一个被试都会更新，因此任务中断后仍能直接查看进度。重新运行 cohort 时，已经有完整 `sub-XXX_manifest.json` 的被试会自动跳过。

## 5. `-Force`

正常全量不要使用 `-Force`。现有正式 stage 在发现完整输出时会自动跳过；发现 partial output 时会停止，避免静默覆盖。

只有你明确检查过现有结果并决定重跑时，才使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_rgb_formal_subject.ps1 `
  -Subject sub-031 `
  -Force
```
