## 5. 当前正式单被试自动流程

已经新增完整正式入口：

```text
scripts/face_formal_prepare.py
scripts/rgb_formal_motion_pose.py
scripts/face_formal_directml.py
scripts/face_formal_derive.py
scripts/run_rgb_formal_subject.ps1
```

总控脚本会显式调用两个 Conda 环境，因此不需要人工在四个阶段之间来回 `conda activate`。

先设置 Face ONNX 模型目录。如果模型仍位于当前测试资产目录，可用：

```powershell
$env:ATTENTION_FACE_MODEL_DIR = "D:\_AttentionData\Beijing-RGB\_test\face-directml\models\pyfeat"
```

然后在仓库根执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_rgb_formal_subject.ps1 `
  -Subject sub-031
```

流程顺序为：

```text
1. 完整正式时间段 timestamp-driven 15 Hz Face frame manifest
2. Motion full-fps + Pose 10 Hz + Pose derived
3. original AVI → Face DirectML full-span inference
4. continuous tracking → primary face → eyelid derived
```

正式输出：

```text
D:\_AttentionData\Beijing-RGB\sub-031\
```

当前下一步就是让 `sub-031` 首次完整跑通。只有这一条从头到尾实机验收通过后，才进入 44 人 batch / resume。

### `-Force` 的使用

默认正式 runner 会尽量识别已经完整完成的输出；如果发现 partial output，会停止而不是静默覆盖。只有确认需要重跑该被试时才使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_rgb_formal_subject.ps1 `
  -Subject sub-031 `
  -Force
```

不要把 `-Force` 当常规启动参数。
