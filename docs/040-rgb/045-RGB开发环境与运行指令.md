### 主 RGB 环境

```powershell
conda activate "D:\CondaEnvs\attention-rgb"
cd "D:\aaawork\07-竞赛\厚璨杯\021-analysisplan\Attention-Analysis-rgb-dev"
```

该环境安装了本项目 `attention_pipeline` 包，所以 `scripts/rgb_analysis.py` 应在这里运行，例如：

```powershell
python scripts/rgb_analysis.py --stage pose-qc --subject sub-031
python scripts/rgb_analysis.py --stage pose-features --subject sub-031
python scripts/rgb_analysis.py --stage face-sample --subject sub-031
python scripts/rgb_analysis.py --stage face-pyfeat-qc --subject sub-031
python scripts/rgb_analysis.py --stage face-libreface-qc --subject sub-031
python scripts/rgb_analysis.py --stage face-continuous-sample --subject sub-031
python scripts/rgb_analysis.py --stage face-continuous-qc --subject sub-031
python scripts/rgb_analysis.py --stage face-visual-review --subject sub-031
```

不要在候选模型独立环境中运行 `rgb_analysis.py`，否则该环境未安装 `attention_pipeline` 时会出现：

```text
ModuleNotFoundError: No module named 'attention_pipeline'
```

### DirectML 独立环境

AMD benchmark 使用单独 runtime，避免 PyTorch / LibreFace / Py-Feat 的 dependency pins 与 ONNX Runtime DirectML 相互污染：

```powershell
conda create -p "D:\CondaEnvs\attention-face-directml" python=3.11 -y
conda activate "D:\CondaEnvs\attention-face-directml"
python -m pip install onnx onnxruntime-directml numpy pandas pyarrow opencv-python pillow
```

检查：

```powershell
python -c "import onnxruntime as ort; print(ort.__version__); print(ort.get_available_providers())"
```

必须看到：

```text
DmlExecutionProvider
```

不要同时在该环境安装普通 `onnxruntime` / `onnxruntime-gpu`。当前 `scripts/face_directml_probe.py` 已强制设置 `enable_mem_pattern=False`、`ORT_SEQUENTIAL`，并通过 ORT profile 记录/检查 execution provider，避免把 CPU fallback 误报成 AMD GPU 性能。

Gate 1 当前只做 ONNX compatibility / provider / fallback / batch model-core smoke，不替代正式 300 帧 parity 与 end-to-end。完整 Gate 0/1 命令和判定规则见：

```text
docs/工作记录/08-26-02-RGB-Face-DirectML-Gate01实现.md
```

## 快速判断当前该用哪个环境

- 命令里是 `scripts/rgb_analysis.py` → **`attention-rgb`**；
- 命令里是 `face_benchmark_pyfeat.py` / `face_export_pyfeat_onnx.py` → **`attention-face-pyfeat`**；
- 命令里是 `face_benchmark_libreface.py` / `face_export_libreface_onnx.py` → **`attention-face-libreface`**；
- 命令里是 `face_directml_probe.py` → **`attention-face-directml`**；
- Git `pull/status/branch` → Conda 环境不重要，但必须在正确 worktree 中。

候选环境只负责 reference inference / model export；模型输出生成后，切回 `attention-rgb` 做 QC、合并和可视化。DirectML runtime 只负责 ONNX GPU 推理和 parity/speed benchmark。
