## 5. Face sample 与 DirectML

采样/时间轴阶段使用 `attention-rgb`：

```powershell
conda activate "D:\CondaEnvs\attention-rgb"
python scripts/face_formal_dryrun_sample.py --subject sub-031
```

真正的 AMD Face GPU 推理切换到：

```powershell
conda activate "D:\CondaEnvs\attention-face-directml"
```

若该环境丢失：

```powershell
conda create -p "D:\CondaEnvs\attention-face-directml" python=3.11 -y
conda activate "D:\CondaEnvs\attention-face-directml"
python -m pip install onnx onnxruntime-directml numpy pandas pyarrow opencv-python pillow
```

Provider 检查：

```powershell
python -c "import onnxruntime as ort; print(ort.__version__); print(ort.get_available_providers())"
```

必须包含 `DmlExecutionProvider`。不要在该环境同时安装普通 `onnxruntime` 或 `onnxruntime-gpu`。

当前 AMD Face 已冻结：

```text
Py-Feat 2.1.1 scientific core
ONNX Runtime DirectML
15 Hz timestamp-driven
RetinaFace B8
multitask B16
identity excluded
```

sub-031 representative dry-run 和第一档工程优化已完成。下一步仍需 sub-033 gap stress、blink event / perclos80_proxy 冻结与 full-video formal runner。

## 6. Reference / export 环境

`attention-face-pyfeat` 与 `attention-face-libreface` 只用于历史 reference、模型导出或诊断；当前 AMD 正式推理不要切回这两个环境。
