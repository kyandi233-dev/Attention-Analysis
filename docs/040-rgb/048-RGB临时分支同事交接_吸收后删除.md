## 3. `51d17c9a...` 中应优先吸收的内容

### A. Parquet stable schema 修复 — 必须审查并保留等价修复

已出现的真实故障：

```text
ArrowNotImplementedError: Unsupported cast from double to null using cast_null
```

根因：流式 Parquet 首个 chunk 某 numeric 字段全部缺失时，PyArrow 将该列推断成 `null`；后续 chunk 出现真实浮点数后无法从 `double` cast 回先前的 `null` schema。

本 commit 的修复原则：

- nullable numeric 明确构造为稳定 numeric dtype；
- nullable integer / boolean / string 同样保持稳定类型；
- 不删除科学字段；
- 不为了绕过 Arrow 错误把数值列强制转成 string/object；
- 首 chunk 全空、后续出现值时仍可连续 append；
- read-back schema 保持正确 numeric type。

请在当前正式 RGB runner 中保留这条原则，即使最终实现不是逐行复制本分支代码。

### B. `tests/test_rgb_formal_schema.py` — 建议吸收

这是对上述故障的最小回归保护。正式 RGB 工作线应保留等价测试：

- 第一批 numeric 列全 missing；
- 下一批出现 float/double；
- parquet writer 不失败；
- 读回列型仍为 numeric nullable schema。

如果你们当前正式 runner 已经换了写出层，请把测试迁移到新的 writer，而不是保留一个不再被正式代码调用的旧测试。
