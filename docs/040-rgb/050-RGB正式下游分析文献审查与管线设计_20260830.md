# 050｜RGB 正式下游分析文献审查与管线设计（2026-08-30）

## 1. 当前仓库结论

RGB 不是“从零开始”。昂贵 raw-first producer 已在历史 `rgb-amd` / `rgb-nvidia` 分支形成 Face/Pose/Motion 输出；临时 `codex/rgb-nvidia-formal-pipeline-v1` 还包含单次解码 producer 与 audit，但它与当前正式主线已严重分叉，不能整体 merge。正式主线应只迁移经过审计的 schema/派生逻辑，并直接消费已保存 Parquet，不重跑视频模型。

历史 raw contract 要求 Face 保存 bbox/confidence/landmarks/AU/expression/head pose/gaze 等 backend 可用输出，Pose 保存 33 个 body landmarks，Motion 保存 timestamp/gap/帧差/global motion 等低成本测量；QC 先 flag，派生和筛选后移。正式 downstream 延续该原则。

## 2. 文献与方法证据

### 2.1 眼睑开合、EAR 与眨眼

Soukupová & Čech (2016)提出使用面部 landmark 构造 Eye Aspect Ratio（EAR）表征眼睛开合，再利用短时间窗的动态模式检测 blink。这个方法支持本项目从已保存 FaceMesh landmark 计算连续眼睑几何，但原论文并不意味着一个固定 EAR 阈值可以跨相机、被试和头姿直接通用。因此正式层保留 EAR、normalized openness、closure trajectory 和 blink candidate；blink 阈值必须通过真实数据 QC/敏感性分析冻结，不能把旧 dry-run 阈值直接升级成正式事实。

Smilek, Carriere & Cheyne (2010, Psychological Science, DOI:10.1177/0956797610368063)显示眨眼行为可与 mind wandering 状态相关。这支持将 blink rate/duration 作为注意状态候选指标，但不支持把 blink rate 单独解释成“注意力分数”。刺激结构、视觉需求、时间进程和个体差异都可能影响眨眼。

### 2.2 PERCLOS

FHWA/FMCSA 1998 技术报告《PERCLOS: A Valid Psychophysiological Measure of Alertness As Assessed by Psychomotor Vigilance》将 PERCLOS 作为 alertness/drowsiness 指标进行验证。它对本项目的价值主要是持续警觉/困倦支持指标，而不是一般性注意或 mind-wandering 的直接 ground truth。因此 PERCLOS 放入 `support_alertness_candidate`，必须报告阈值定义、有效眼睑 coverage、窗口长度和敏感性分析。

### 2.3 Face、Action Units、head pose 与 gaze

OpenFace 2.0（Baltrušaitis et al., 2018, DOI:10.1109/FG.2018.00019）提供 landmark、head pose、action unit 和 gaze 等自动面部行为接口。Py-Feat（Cheong et al., 2023, Affective Science, DOI:10.1007/s42761-023-00191-4）进一步提供自动面部特征提取、预处理和分析框架。两者证明这些字段适合作为可量化的人类行为表征，但 AU/emotion/head-pose 不能未经本实验验证直接解释为注意力高低。正式层将 AU activity/variability、head-pose level/variability/velocity、gaze variability（若 raw 中存在）纳入候选或 confound/support registry，并进行 coverage、分布、重复测量、冗余和结局验证。

### 2.4 Body pose 与动作量

BlazePose（Bazarevsky et al., 2020, arXiv:2006.10204）实时输出 33 个 body keypoints。历史 RGB schema 已完整保存 Pose landmarks，因此正式下游可以在不重跑 MediaPipe 的前提下计算 shoulder/trunk/head/wrist 等位置和速度、姿态稳定性及 upper-body movement。关键点 visibility/presence 必须作为 QC；低 visibility 不能静默插值成真实动作。

### 2.5 MediaPipe Face Mesh

MediaPipe Face Mesh 的公开方法文档说明其输出 468 个 3D face landmarks；refine-landmarks 模式还可提高眼区/虹膜区域精度。历史 RGB producer 已据此采用 FaceMesh mesh 点计算 EAR/眼睑 aperture。正式层保留此计算，但 RGB iris 像素信息只可作为眼睑尺度/几何辅助，不取代 NIR pupil-only 生理信号。

## 3. 本项目正式候选指标

### 3.1 Ocular / eyelid

- EAR left/right/mean；
- normalized eye openness；
- closure fraction；
- blink candidate count/rate/duration/inter-blink interval；
- PERCLOS candidate（阈值和窗口为预注册/敏感性对象）；
- left-right asymmetry（优先作为 QC/support）；
- eye/face valid coverage。

### 3.2 Face / AU / head-gaze

- 每个实际存在 AU 的均值、中位数、SD/MAD/IQR、activity fraction、短时变化率；
- head yaw/pitch/roll level、variability、absolute velocity；
- gaze magnitude/variability（仅当 raw schema 支持）；
- face bbox area/center movement、face detection/primary-track coverage、multi-face fraction。

### 3.3 Pose / body

- head/shoulder/trunk landmark visibility coverage；
- shoulder center、wrist、elbow、head/nose 等运动速度与 robust variability；
- shoulder-line orientation、trunk lean/upper-body displacement（只有 landmark schema 足够时）；
- left/right body asymmetry作为候选/QC，而非默认注意力 endpoint。

### 3.4 Global motion

- `global_motion_energy` / `global_motion_energy_per_sec`；
- `changed_pixel_ratio`；
- gray mean/变化作为视觉/曝光 QC；
- gap/irregular-dt/capture-missing 必须保留并从依赖前帧的运动统计中剔除。

## 4. 正式数据层

```text
历史 RGB raw-first producer outputs
  ↓（只读，不重跑模型）
20_rgb_analysis_ready
  ├─ face_derived
  ├─ pose_derived
  ├─ motion_derived
  └─ qc / schema / provenance
  ↓
21_rgb_analysis_tables
  ├─ trial
  ├─ probe_pre_10s / 20s / 30s
  ├─ cycle / block / session
  ├─ time_on_task
  ├─ candidate_validation / redundancy / endpoint_decisions
  ├─ within_between
  ├─ inference / model_failures
  ├─ prediction_folds
  └─ figures / figure_manifest / coverage_audit
```

所有 probe window 必须 strictly pre-probe：同 block、trial onset < probe onset、trial number < anchoring probe trial；禁止锚定 trial 和 post-probe 信息泄漏。

## 5. 统计原则

session 是采集单元，`participant_key`/正式 participant group 是推断、bootstrap、cluster 和 CV 单元。重复 session 不得当独立参与者。候选指标先做 calculability、coverage、floor/ceiling、between/within、time-on-task、repeat stability、redundancy；最终 endpoint 决策保持 `pending_real_data_scientific_review`，不得按 outcome p-value 筛选。

解释性模型与预测严格分开。解释层优先 LMM/GEE/ordinal/multinomial 等参与者聚类模型；预测层 participant-exclusive folds，标准化/特征选择只在 training fold 内完成。模型失败必须写表，不能输出空文件假装成功。

## 6. 图表 contract

与 Behavior/NIR 相同：**图内不得有标题**；中文坐标轴/图例；完整题名和科学解释写外部 caption manifest；每个保留候选指标在规定尺度必须 `generated` 或 `not_estimable + reason`。核心图、支持图、QC/流程图分层。

## 7. 不能过度解释的内容

- blink/PERCLOS ≠ 通用注意力 ground truth；
- AU/emotion output ≠ 被试真实主观情绪标签；
- head/body motion ≠ 注意力下降本身；
- RGB iris geometry ≠ NIR pupil diameter；
- 单个 raw frame 的模型 score 不应直接作为参与者级独立样本。

## 8. 当前冻结边界

rPPG 继续排除在当前正式 RGB scope 外；如果未来重新加入，需要单独文献、信号质量和采样/光照验证。历史 producer 不整体 merge；只迁移本报告所需 downstream 逻辑。
