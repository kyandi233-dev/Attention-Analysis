# 00｜跨模态目录与映射

## 当前状态（2026-08-23）

跨模态作为独立研究层继续保留，但当前仓库没有已经冻结的 NIR + RGB + 行为融合实现，也不产生融合后的“专注评分”。

NIR 正式全量分析已经完成，但这并不自动意味着跨模态融合可以启动。融合前仍需要分别明确：

- NIR 最终变量与 QC 口径；
- RGB 是否重新启用及其测量质量；
- 正式行为指标与时间窗；
- 各模态时间同步方式；
- 缺失模态与不同采样率的处理；
- 融合的统计/机器学习目标和验证方案。

因此本目录继续作为未来跨模态设计的稳定入口，不与 `010-nir`、`020-rgb` 或 `050-sart-formal` 合并，也不因为当前没有实现而删除。
