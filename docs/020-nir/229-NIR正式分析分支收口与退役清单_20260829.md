## 收口后的代码边界

正式 NIR 下游固定为：

`fullclass-final production → pupil-only adapter → 10_analysis_ready → 11_analysis_tables → 12_pipeline_validation / Figure01–10`

正式分析不得恢复 PIR / iris_outer 作为主指标；没有独立、可信 iris geometry 时 PIR/OAR 必须 fail closed。validation 不得绕过 staged manifest 直接读取 production。行为正式分析使用 44 session / 38 analysis groups / 6 double-session repeat groups 三个不同计数轴，并对 Go omission / No-Go commission、Q1 nominal / Q2 ordinal repeated model、probe anchor exclusion、participant-disjoint prediction 和 failure tables 分别设门。
