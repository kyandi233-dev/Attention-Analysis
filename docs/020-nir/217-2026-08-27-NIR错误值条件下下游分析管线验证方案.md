## 2. 当前这些被试可以验证什么

### 2.1 Behavior-only 描述

行为数据本身可用于检查：

- 每 Block trial 数；
- overall accuracy；
- correct Go RT median / MAD；
- No-Go commission rate；
- Go omission rate；
- probe 数量。

这部分不依赖 PIR，但当前只有部分被试完成 `11_analysis_tables`，因此也不视为最终 cohort 结果。

### 2.2 Block 与 time-on-task

假定 PIR 正确，验证：

- subject 内 Block1 / Block2 PIR 汇总；
- 1 s 表能否进一步汇总成 30 s 展示轨迹；
- subject trajectory、cohort median 与 IQR 是否能正常生成；
- Block 作为固定效应、subject 作为随机截距的 mixed model 是否能运行。

### 2.3 Trial-level

固定使用 `binocular_primary`，示范窗口固定为 `pre_5s`，不是根据当前结果选择。

验证：

```text
go_correct
go_omission
nogo_correct
nogo_commission
```

四类 trial 与 pre-trial PIR 的数据合并、分组和图形输出。

同时测试：

- correct Go RT ~ PIR；
- No-Go commission ~ PIR；
- Go omission ~ PIR；
- subject 内 / subject 间 PIR 分解。

### 2.4 Probe-level

所有 `pre_10s / pre_20s / pre_30s / pre_60s` 用于绘图比较。模型 smoke test 固定用 `pre_20s`，同样不是根据当前效应选择。

验证：

- probe vigilance 与 pre-probe PIR 的数据接口；
- 多窗口并列图；
- probe-level mixed model 是否能够正常拟合。

### 2.5 Coverage / 数据质量可视化

继续验证：

- trial-window `pir_valid_fraction_median`；
- subject×Block coverage heatmap；
- 当前 window 和 track 是否有系统性缺失。

这一部分属于真实的管线 QC，即使 PIR 数值错误，时间覆盖与文件结构仍然有工程参考价值。

## 5. Smoke-test 模型

当前代码尝试运行：

```text
LMM 1:
PIR ~ time_in_block × Block + (1 | subject)

LMM 2:
Go RT ~ PIR_within + PIR_between + time + Block + (1 | subject)

GEE 1:
No-Go commission ~ PIR_within + PIR_between + time + Block

GEE 2:
Go omission ~ PIR_within + PIR_between + time + Block

LMM 3:
Probe vigilance ~ PIR_within + PIR_between + Block + (1 | subject)
```

其中：

```text
PIR_between = subject mean PIR
PIR_within  = current PIR - subject mean PIR
```

这一步提前验证未来正式模型最重要的 within-person / between-person 分离接口。

模型如果因为当前样本太少、某个 binary outcome 没有两个水平、数值奇异等原因无法拟合，记录为 `skipped` 或 `failed`，不会阻塞其他图表输出。

## 7. 当前可以看、不能看

可以看：

- 文件是否能完整读取；
- trial / probe / time-on-task join 是否正确；
- 行数与键是否合理；
- 图是否专业、信息层级是否合理；
- mixed model / GEE 接口是否正常；
- 哪些模型因数据结构而失败；
- coverage / missingness 图。

不能看：

- PIR 是升还是降；
- Block1/Block2 谁更高；
- PIR 是否预测错误；
- PIR 是否预测 vigilance；
- p 值或置信区间是否“显著”；
- 哪个窗口效果最好。
