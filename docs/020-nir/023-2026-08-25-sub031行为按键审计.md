# sub-031 行为按键审计

> 2026-08-25（Asia/Shanghai）｜工作分支：`amd-DirectML`。本文件是 NIR 正式分析规划的单被试行为侧 pilot audit，用于冻结后续 trial-level 行为 QC 需要保留的原始字段与风险模式。当前只基于 sub-031 的两个正式 B block，不把这些数量直接推广到 116 名正式样本。

## 2. sub-031 的实际按键结构

864 个正式 trials 中：

- `response=1`：777 trials
- `response=0`：87 trials
- `raw_keypresses` 解析为 0 次：87 trials
- 解析为 1 次：756 trials
- 解析为 2 次：21 trials
- `prestimulus_press_ms` 非空：5 trials
- omission：32 trials
- commission：41 trials

记录的 `rt` 与 `raw_keypresses` 第一枚 Unix-ms 时间戳减去 `absolute_onset_time` 高度一致，说明当前 `rt` 本质上对应当前 trial onset 之后捕获到的**第一次正式按键**。后续重复按键保留在 `raw_keypresses`，不会覆盖首次 RT。

## 3. 极短与极晚 RT

sub-031 正式 trials 中观察到：

- `rt < 100 ms`：44 trials
- `rt < 150 ms`：75 trials
- `rt < 200 ms`：124 trials
- `rt > 900 ms`：6 trials
- `rt > 1000 ms`：3 trials

最短记录接近 0 ms，说明行为数据中确实存在几乎与 stimulus onset 同时发生的按键。不能把所有 `response=1` 的 trial 都直接解释成正常刺激驱动反应；需要独立建立 anticipatory-response QC。

正式阈值目前**不冻结**。例如 100/150/200 ms 都只能作为候选检查点，最终要结合 116 人总体 RT 分布、任务节奏与连续 trial 模式确定，而不是只根据 sub-031 设阈值。

## 4. `prestimulus_press_ms` 的实际证据

sub-031 共发现 5 个 `prestimulus_press_ms` 非空 trial，全部出现在 Block 2；这 5 个 trial 均为 Go trial，且程序原始评分全部为：

```text
response = 0
omission = 1
rt = NaN
```

这些 prestimulus presses 距当前 trial 的 `absolute_onset_time` 分别约：

```text
-5 ms
-21 ms
-33 ms
-4 ms
-5 ms
```

即按键发生在当前水果 onset 前极短时间内。这直接证明了此前担心的一类情况在真实数据中存在：

> 被试已经在当前 trial 出现前抢先按键，但因为它落在 prestimulus 区间，该 trial 仍可被程序记为 omission。

因此后续不应把所有 omission 都视为同质的“完全没有按键”。至少需要区分：

```text
clean_omission
prestimulus-associated_omission
```

但不直接把 prestimulus press 人工改判成当前 trial 的正确反应；原始评分轨与 QC/敏感性轨应并存。

## 5. 两次按键与下一 trial 的关系

21 个 trial 在 `raw_keypresses` 中包含两枚按键。第二枚按键经常位于当前 trial 后期，并接近下一 trial onset。

其中 13/21 个双按 trial 的第二枚按键发生在**下一 trial onset 前 200 ms 内**；这 13 个之后的下一 trial 中，有 8 个被程序记为 omission。

这说明另一类连续行为风险模式也真实存在：

```text
当前 trial 第一次正常/偏早按键
        ↓
当前 trial 后期再次按键
        ↓
第二枚按键非常接近下一 trial onset
        ↓
下一 trial 可能不再按键
        ↓
下一 trial 被记为 omission
```

这里只能定义为“潜在 anticipatory carry-over / ambiguous sequence”，不能仅凭时间邻近就把第二枚按键重新归属到下一 trial。Probe 插入、trial 间时序、真实被试意图都可能影响解释。

## 7. 对 NIR trial-level 分析的影响

NIR 与行为对齐时不能只使用 `correct/omission/commission` 作为行为标签。至少需要把原始程序评分与行为 QC 标签同时带入，以避免把明显的 anticipatory motor pattern 误解释成纯粹的 sustained-attention failure。

建议正式模型分层：

1. **Primary behavioral scoring**：保持程序原始定义；
2. **QC-aware primary/sensitivity model**：排除或单列明确的 prestimulus / 极短 RT / ambiguous sequence；
3. **Exploratory motor-timing analysis**：把 anticipatory response 本身作为注意控制失败的一类行为表型，而不是简单当作脏数据删除。

这对 No-Go/Go 两类 trial 尤其重要：commission、omission、anticipatory press 可能分别反映不同形式的反应抑制/持续注意失败，不应在一开始被压缩成单一 accuracy 指标。
