# 211｜左右眼 PIR 处理与标准化冻结决策

> 2026-08-26｜适用于北京 NIR cohort downstream analysis。本文基于 Issue #16 的 44 人左右眼测量结构与质量分层敏感性结果，并结合 Issue #17 的 time-bin coverage calibration，冻结后续 PIR 的 eye-handling（左右眼处理）与 standardization（标准化）原则。本文不定义新的 subject/eye/Block 全局排除阈值；帧级 PIR usable 仍以 `029-2026-08-26-PIR有效性与usable筛选定义.md` 为准。

## 1. 证据摘要

Issue #16 的 88 个 subject×Block 中，全部记录（Tier 0）的左右眼 median PIR：

- Pearson r = 0.568611；
- Spearman rho = 0.788912；
- ICC(A,1) = 0.525027；
- ICC(C,1) = 0.522550；
- median left-right offset = -0.001673；
- Bland–Altman LoA = [-0.126831, 0.131915]。

当仅作为敏感性复核、逐步要求双眼 usable fraction 更高时，cohort-level agreement 明显增强：

| 质量层级 | N subject×Block | Pearson | Spearman | ICC(A,1) | ICC(C,1) |
|---|---:|---:|---:|---:|---:|
| Tier 0：全部 | 88 | 0.568611 | 0.788912 | 0.525027 | 0.522550 |
| Tier 1：双眼均 ≥0.50 | 60 | 0.831691 | 0.802779 | 0.820403 | 0.824474 |
| Tier 2：双眼均 ≥0.80 | 36 | 0.910880 | 0.901416 | 0.906601 | 0.910816 |
| Tier 3：双眼均 ≥0.90 | 23 | 0.891632 | 0.846838 | 0.886492 | 0.889945 |

同时，exact-timestamp within-block correlation 仍低于 cohort-level median agreement。Pearson median 从 Tier 0 的 0.370309 提升到 Tier 2/3 的约 0.493/0.504，Spearman median 提升到约 0.693。

因此，证据支持三点同时成立：

1. 低质量单眼会明显拉低左右眼总体 agreement；
2. 高质量双眼在总体 PIR 水平上可以高度一致；
3. 即使双眼质量较高，逐帧动态也不能视为完全等价的重复测量。

所以后续既不采用“无条件逐帧平均两眼”，也不采用“永远只取固定单眼”。

另外，Issue #17 表明 window coverage 门槛本身会显著改变 binocular / fallback / unavailable 的构成。例如 60 s paired bins 中，候选 threshold 0.50 时 both/either/single/neither 约为 64.3%/92.8%/28.4%/7.2%，而 threshold 0.80 时约为 36.2%/77.3%/41.1%/22.7%。因此“是否双眼融合”不能仅由一个 coverage 数字决定，还必须在双眼都具有足够数据后检查两眼是否真正一致。

## 2. 冻结的左右眼处理政策

### 2.1 帧级继续保留 eye 身份

正式 frame-level 数据继续保留：

```text
subject × block × eye × time
```

不得在原始/帧级数据表中提前把左右眼合并成单列，也不得用一只眼覆盖另一只眼。

原因：逐帧左右眼同步只有中等水平，并且部分被试存在明显单眼质量失败；提前平均会把低质量眼直接混入高质量眼。

### 2.2 第一层：每只眼独立通过 window gate

对 baseline、time-bin、trial window、probe window 等分析单元：

1. 先分别对 left/right 使用各自 usable frames 计算 PIR 特征；
2. 分别计算每只眼在该分析单元内的 coverage、usable N 与时间代表性；
3. 按该分析类型预先冻结的 window-level gate 判断每只眼是否合格。

第一层只回答“这只眼在这个窗口有没有足够、分布合理的数据”，不回答左右眼彼此是否一致。

第一层的结果只有四种：

```text
左不合格 + 右不合格
→ PIR unavailable

左合格 + 右不合格
→ left-only single-eye fallback

左不合格 + 右合格
→ right-only single-eye fallback

左合格 + 右合格
→ 进入第二层 binocular concordance gate
```

### 2.3 single-eye fallback 的严格边界

single-eye fallback 只发生在：

> **该分析窗口中恰好只有一只眼通过预先冻结的 window-level quality / coverage gate。**

它不表示整名被试永久指定为左眼或右眼。

因此同一被试可能：

- 某个窗口双眼都合格；
- 另一个窗口仅左眼合格；
- 再一个窗口仅右眼合格；
- 某些窗口双眼都不可用。

如果两眼都通过 window gate 但彼此明显冲突，**不能**把这种情况重新解释成 single-eye fallback，也不能事后挑选“更符合理论/更显著”的那只眼。

### 2.4 第二层：双眼都合格时检查 binocular concordance

双眼都通过第一层 gate 后，还必须检查两眼是否在表达一致的 PIR 变化。

这里不能直接用 raw PIR 的绝对左右眼差作为唯一依据，因为两只眼可能存在稳定 baseline offset。例如左眼长期 baseline 为 0.25、右眼为 0.35，但当前两眼分别升到 0.28 与 0.38；raw PIR 相差 0.10，但两眼相对于各自 baseline 都增加了 0.03，实际上是高度一致的变化。

因此 binocular concordance 应优先比较：

```text
subject×eye baseline-adjusted 的同定义窗口特征
```

主 level 特征优先基于 `PIR_centered`；robust-z 可作为尺度统一后的 sensitivity。

### 2.5 双眼一致时才允许 binocular mean

若两眼均通过第一层 window gate，且 baseline-adjusted 同定义特征满足预先冻结的 concordance rule：

```text
fusion_mode = binocular_mean
n_eyes_contributing = 2
```

对左右眼已经分别计算好的**同尺度、同定义特征**做简单等权平均。

目前不采用按 `usable fraction` 连续加权的质量加权平均，因为：

- usable fraction 是有效帧比例，不等价于测量误差方差；
- 质量加权会引入额外模型假设；
- 现有 44 人结果不足以证明某种加权函数优于简单等权平均。

### 2.6 双眼都高质量但明显冲突时怎么办

如果两眼都通过 window gate，但 baseline-adjusted 特征明显 discordant，例如一眼显示明显增加、另一眼显示明显减少，则：

```text
fusion_mode = binocular_discordant
n_eyes_contributing = 2
```

处理规则：

- 不强行求平均；
- 不把两眼相反变化平均成接近 0 的“无变化”；
- 不事后选择其中一眼；
- 主融合分析中该窗口不生成一个 binocular single value；
- 左右眼原始/centered 特征完整保留；
- 进入 eye-preserved sensitivity 时仍可作为两条 eye-level repeated observations 使用。

**binocular discordance 的具体数值阈值当前尚未冻结。** 这一阈值必须在查看 time-on-task / Behavior / Probe outcome 效应之前，基于双眼高质量窗口的测量分布完成校准。

### 2.7 下游必须记录的眼别状态

至少保留：

```text
left_eye_pass_window_gate
right_eye_pass_window_gate
left_eye_feature
right_eye_feature
n_eyes_contributing
fusion_mode = binocular_mean / left_only / right_only / binocular_discordant / unavailable
```

必要时再记录：

```text
binocular_difference_centered
binocular_difference_robust_z
binocular_concordance_pass
```

## 3. 左右眼敏感性分析

后续主要 PIR 结果至少保留两类 sensitivity：

1. **bilateral-only concordant**：只使用同一分析单元中两眼都通过 window gate 且通过 binocular concordance gate 的记录；
2. **eye-preserved**：left/right 不融合，把 eye 作为重复测量层级或分别估计，以检查融合后结论是否由某一眼或融合逻辑驱动。

必要时还可报告 left-only / right-only 描述，但不把“选择结果更显著的那只眼”作为正式策略。

Tier 1/2/3（0.50/0.80/0.90）只用于 Issue #16 证明质量与 agreement 的关系，**不是正式 eye exclusion cutoff**。

## 4. PIR 标准化冻结决策

后续同时保留以下版本，但角色不同。

### 4.1 Raw PIR：绝对水平和个体差异描述

```text
raw PIR = fullclass_pupil_to_iris_diameter_ratio
```

用途：

- 个体 baseline 描述；
- Block1 vs Block2 原始量级变化；
- between-subject difference；
- 方法报告和可解释的原始效应量。

raw PIR 不因标准化而被覆盖或删除。

### 4.2 Primary within-subject measure：subject×eye median-centered PIR

正式个体内动态分析的主要候选冻结为：

```text
PIR_centered = PIR - median(PIR_subject,eye)
```

这里的 baseline 使用该被试该只眼在当前分析数据范围内全部 usable PIR 的 median，而不是分别按 Block 重新中心化。

原因：

- 可以去除稳定的 subject×eye baseline offset；
- 保留 Block1→Block2 的整体水平变化；
- 不改变每只眼内部的 Pearson/Spearman 时序结构；
- 适合比较“当前相对于该被试该眼自身典型水平变化了多少”；
- 与“先按眼计算、再条件融合”的 eye-handling 兼容。

后续 time-on-task、Behavior、Probe 的**个体内 PIR 变化**优先使用此版本。

### 4.3 群体分析不是“只分析个人”

subject×eye centered 并不意味着最终只做每个被试自己的结果。它的作用是先把稳定的个体/眼别 baseline 分开，再把所有被试的 repeated observations 一起放入 mixed-effects model。

正式群体模型应区分：

```text
PIR_between = subject×eye/session baseline
PIR_within  = current PIR - PIR_between
```

这样可以同时回答：

1. **within-person effect**：同一个人相对自己 baseline 的 PIR 变化是否与专注/警觉状态变化相关；
2. **between-person effect**：平均 PIR baseline 较高的人，是否在总体专注、行为或问卷指标上不同。

因此不建议把所有被试先平均成一条 PIR 曲线后再做简单相关；那会把个体差异与状态变化混在一起。

### 4.4 Robust-z：稳健性/尺度统一分析

```text
PIR_robust_z = (PIR - median_subject,eye) / (1.4826 × MAD_subject,eye)
```

用途：

- sensitivity analysis；
- 需要把不同被试动态幅度统一到相近尺度的模型；
- 多变量特征组合/机器学习前的候选标准化；
- binocular concordance 的尺度统一 sensitivity。

如果 `MAD` 为 0、近 0 或不可稳定估计，必须标记 denominator failure，不得强行除法。

robust-z 的差值单位是 robust SD-like units，不能与 raw/centered PIR 的绝对差值直接比较大小。

### 4.5 Subject×eye×Block centering：不作为主方案

```text
PIR_block_centered = PIR - median(PIR_subject,eye,block)
```

该版本会按定义消除每个 Block 的中心差异，因此：

- 不用于 Block1 vs Block2、vigilance decrement 或长期 time-on-task 主分析；
- 仅在明确只研究 Block 内短时波动、且不关心 Block 水平差异时作为 sensitivity candidate。

## 5. 预测任务的信息泄漏边界

对于传统解释性/推断性分析，使用完整实验内 subject×eye median 进行 centered 描述是允许的。

但如果后续目标是在线/前瞻 prediction：

- 不得用未来时段数据计算当前时刻的 baseline；
- normalization 参数必须只来自 training fold、历史窗口或预先定义的 calibration period；
- cross-validation 必须以 subject 为分组单位，避免同一被试未来信息泄漏到训练端。

因此“推断分析的 subject×eye median-centered”与“在线预测的 causal normalization”必须分开实现。

## 6. 后续分析单元的固定数据流

```text
full-class frame
↓
029 定义的 PIR usable frame
↓
按 subject × eye 生成 raw / centered / robust-z
↓
按分析窗口分别计算 left/right feature + coverage + temporal representativeness
↓
第一层：应用该分析类型预先冻结的 per-eye window gate
↓
两眼均不通过
→ unavailable

仅左眼通过
→ left_only single-eye fallback

仅右眼通过
→ right_only single-eye fallback

两眼都通过
→ 第二层 binocular concordance gate
        ↓
        concordant
        → binocular equal-weight mean

        discordant
        → 不强行平均
        → binocular_discordant
        → 保留 eye-level sensitivity
↓
群体 mixed-effects model
↓
bilateral-only concordant + eye-preserved sensitivity
```

window-level coverage 与 binocular concordance 的具体数值阈值尚未在本文定义。它们必须在对应正式分析前依据采样完整性、时间代表性与测量分布冻结，而不能依据显著性结果选择。

## 7. 正式报告可用方法表述

> 瞳孔指标采用瞳孔与外虹膜几何平均直径之比（PIR）。仅保留通过预设瞳孔–虹膜几何有效性门控且 PIR 为有限数值的帧。左右眼首先独立进行质量控制、subject×eye baseline 校正与时间窗特征提取。随后在每个具体分析窗口内分别判断左右眼的有效覆盖率与时间代表性：双眼均不满足窗口质量标准时，该窗口 PIR 记为不可用；仅单眼满足标准时，使用该眼作为 single-eye fallback；双眼均满足标准时，进一步比较经 subject×eye baseline 校正后的同定义特征，只有双眼结果满足预设一致性标准时才进行等权融合。双眼均高质量但结果明显冲突的窗口不强行平均，而标记为 binocular-discordant，并保留左右眼独立特征用于 eye-preserved sensitivity。主要个体内变化指标采用 subject×eye median-centered PIR，同时保留 raw PIR 用于绝对水平和个体差异描述，并以 robust-z 作为稳健性分析。群体推断采用 mixed-effects framework，将 within-person PIR change 与 between-person PIR baseline 区分估计，而不是先把所有被试平均成一条曲线。

最终报告需同时报告每个模型实际使用的 subject 数、analysis-unit 数、binocular mean / single-eye fallback / binocular-discordant / unavailable 比例与 coverage 排除数量。
