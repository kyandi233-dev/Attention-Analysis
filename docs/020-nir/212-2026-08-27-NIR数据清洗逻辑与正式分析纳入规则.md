# 212｜NIR 数据清洗逻辑与正式分析纳入规则

> 2026-08-27｜适用于北京 NIR `ritnet-fullclass-v1.2-fast-qc` 数据的正式统计分析。本文定义从原始 RITnet 逐帧结果到正式分析数据的清洗逻辑，并区分“生产字段”“正式主分析纳入规则”和“严格敏感性分析规则”。

## 1. 术语与分析对象

### 1.1 RITnet 四分类分割

RITnet 是用于近红外眼部图像语义分割的深度学习模型。当前正式流程把每个眼部图像像素分为四类：

| 类别 | 英文 | 中文含义 |
|---|---|---|
| class 0 | background | 背景 |
| class 1 | sclera | 巩膜 |
| class 2 | iris | 可见虹膜组织 |
| class 3 | pupil | 瞳孔 |

### 1.2 ROI

ROI（region of interest，感兴趣区域）指送入后续眼部分析的局部眼睛图像区域。当前 full-class 指标统一在 320×160 的分析坐标中计算。

`roi_clipped` 表示由 YOLO 眼框向外扩展后的裁剪区域碰到原视频画面边界。它不等价于“眼球结构被截断”，因此不作为正式 PIR 硬性剔除条件。

### 1.3 PIR

PIR（pupil-to-iris diameter ratio，瞳孔/虹膜直径比）是本研究正式瞳孔指标，用外虹膜尺度对瞳孔尺度进行归一化，以降低拍摄距离、眼睛大小和局部成像尺度差异的影响。

当前定义为：

```text
D_pupil = sqrt(pupil_axis_a × pupil_axis_b)
D_iris  = sqrt(iris_axis_a × iris_axis_b)
PIR     = D_pupil / D_iris
```

其中外虹膜区域定义为：

```text
iris_outer = iris OR pupil
```

即 class 2 与 class 3 的联合区域。PIR 并不是“瞳孔像素数 / 虹膜像素数”，而是基于瞳孔与外虹膜主体轮廓拟合椭圆后的几何平均直径之比。

这一点很重要：孤立的小块错误分割如果没有进入最终用于椭圆拟合的主体轮廓，通常不会直接改变 PIR。

## 2. 为什么修订原先的 edge 硬剔除规则

生产阶段的 `fullclass_normalization_valid` 使用了较严格的 whole-mask edge 规则。whole-mask edge（整张分割掩膜触边）指：只要 pupil 或 iris_outer 的二值 mask 在 320×160 图像最上、最下、最左或最右边界出现任意像素，就记为触边。

该规则的优点是保守，但它检查的是整个分割 mask，而 PIR 椭圆拟合实际使用的是最大主体轮廓。因此，眼球外部出现一个孤立的错误 iris/pupil 小块并触碰边界时，即使真正的主体 pupil/iris 轮廓完全正常，旧规则仍会把整帧判为无效。

44 人 frame-level 审计显示：

| 审计结果 | 数值 | 解释 |
|---|---:|---|
| 正式 Block1/Block2 总帧数 | 2,919,835 | 当前审计总体 |
| pupil whole-mask edge | 6.548% | 整个 pupil mask 任意像素触边 |
| iris_outer whole-mask edge | 14.729% | 整个外虹膜 mask 任意像素触边 |
| normalization-invalid | 753,135 帧（25.794%） | 旧生产规则下无效 |
| 仅 edge gate 失败、其他 gate 均通过 | 380,163 帧 | 占旧 invalid 的 50.48% |
| sparse edge-only 样本中严格 stray-only | 277/288（96.18%） | 主体最大轮廓未触边，仅孤立小块触边 |

这里的 stray-only（孤立误分割小块触边）是指：整个 mask 碰到边界，但实际用于主体结构表示的最大轮廓没有碰到边界。

因此，现有证据表明 whole-mask edge 作为主分析硬剔除条件过于保守，可能产生较多 false rejection（假性剔除，即本来仍具有可解释 PIR 的帧被删除）。

需要同时强调：sparse QC 只覆盖有限的可重建标签样本，因此不能把 96.18% 直接外推为全部 2,919,835 帧的真实比例。该结果用于支持“whole-mask edge 不适合作为主分析唯一硬门控”的方法决策，而不是估计全量 stray-patch 的精确发生率。

## 3. 正式主分析的逐帧 PIR 纳入规则

正式主分析采用 relaxed frame-level validity（宽松但仍保留核心几何约束的逐帧有效性）。

一只眼在某个时间点的 PIR 进入主分析，必须满足：

```text
1. pupil ellipse fit valid
2. iris outer ellipse fit valid
3. pupil center 位于 iris outer 主体轮廓内部或边界上
4. D_iris > D_pupil
5. PIR 为有限数值（不是 NaN、+inf、-inf）
```

对应下游建议派生字段：

```text
pir_valid_primary
```

逻辑等价于：

```python
pir_valid_primary = (
    pupil_fit_valid
    and iris_outer_fit_valid
    and pupil_center_in_iris_outer
    and iris_outer_geom_mean_diameter > pupil_geom_mean_diameter
    and PIR_is_finite
)
```

### 为什么保留这些条件

| 条件 | 保留原因 |
|---|---|
| pupil ellipse fit valid | 没有有效瞳孔椭圆就无法得到可靠瞳孔尺度 |
| iris outer ellipse fit valid | 没有有效外虹膜椭圆就无法得到可靠归一化分母 |
| pupil center in iris outer | 保证瞳孔与外虹膜具有正常嵌套关系 |
| `D_iris > D_pupil` | 排除明显不符合眼部结构的几何结果 |
| PIR finite | 排除数值层面的 NaN 或无穷值 |

### 不再作为主分析硬剔除条件的指标

以下变量继续保留用于质量控制（quality control，QC）和敏感性分析，但不再单独决定主分析逐帧 PIR 是否纳入：

- `pupil_touches_roi_edge`：整个 pupil mask 是否触及 320×160 分割图边界；
- `iris_outer_touches_roi_edge`：整个 iris_outer mask 是否触及边界；
- `roi_clipped`：扩展后的 YOLO ROI 是否碰到原视频边界；
- fragmentation diagnostic（分割碎片诊断）：例如眼部区域存在多个连通块、最大连通块占比偏低；
- pupil confidence（瞳孔置信度）：仅作为辅助诊断，不能单独证明分割质量；
- blur diagnostic（模糊度诊断）：例如 Laplacian variance，仅保留诊断值，目前不设置正式模糊度 cutoff（阈值）。

少量分割噪声允许作为测量误差保留，后续通过时间聚合、稳健统计、重复测量模型以及严格敏感性分析评估其影响，而不再为了消除所有局部误差而大量牺牲可用数据。

## 4. 严格敏感性分析规则

为了保留与既有生产 `fullclass_normalization_valid` 的可比性，同时检查正式结论是否依赖新的 relaxed 规则，后续保留一套 strict sensitivity definition（严格敏感性定义）。

建议派生字段：

```text
pir_valid_strict
```

定义为：

```python
pir_valid_strict = (
    fullclass_normalization_valid
    and PIR_is_finite
)
```

即继续要求旧生产规则中的：

```text
pupil whole-mask 不触边
AND
iris_outer whole-mask 不触边
```

主分析和敏感性分析的关系如下：

| 数据定义 | 用途 |
|---|---|
| `pir_valid_primary` | 正式主分析，避免 whole-mask stray patch 造成过度剔除 |
| `pir_valid_strict` | 严格敏感性分析，与历史 `normalization_valid` 保持可比 |

如果主分析与 strict sensitivity 在方向和效应量上基本一致，可以说明结论并不依赖 edge gate 的具体定义；如果两套规则得到明显不同结论，则必须在结果中报告并讨论数据质量规则对估计的影响。

## 5. 左右眼的逐时间点处理

左右眼首先独立完成逐帧质量判断，不再先以 30 s 或 60 s 时间窗决定“整段使用哪只眼”。

对每个 timestamp（时间点）：

| 左眼 | 右眼 | 连续 PIR 状态 |
|---|---|---|
| 有效 | 有效 | 两眼均保留，进入双眼融合步骤 |
| 有效 | 无效 | left-only，仅左眼贡献 |
| 无效 | 有效 | right-only，仅右眼贡献 |
| 无效 | 无效 | missing，该时间点无 PIR |

这里的“有效”首先按 `pir_valid_primary` 判断。`pir_valid_strict` 作为平行的严格敏感性轨道保留。

双眼都有有效 PIR 时，应先在每只眼内部完成 baseline adjustment（基线校正，例如 subject×eye median centering，被试×眼中位数中心化），再构造共同尺度上的 binocular PIR（双眼 PIR）。左右眼原始轨道仍需永久保留，不能在生成双眼序列后删除。

后续正式分析表应至少保留：

```text
left_raw_PIR
right_raw_PIR
left_centered_PIR
right_centered_PIR
left_valid_primary
right_valid_primary
left_valid_strict
right_valid_strict
binocular_PIR
binocular_source_mode
```

其中 `binocular_source_mode` 至少区分：

```text
binocular
left_only
right_only
missing
```

不因为某一时间段只有一眼可用而删除整个被试、整个 Block 或对应 Behavior trial。

## 6. 时间窗 coverage 的正确定位

coverage（有效覆盖率）指某个分析区间中有效 PIR 数据占理论可观测数据的比例。

它不再用于基础逐帧清洗，而只用于回答：

> 一个 trial、probe 前窗口或描述性 time-bin 中，剩余的有效数据是否足以代表这个分析区间。

因此正式流程是：

```text
原始逐帧 RITnet 结果
        ↓
逐眼计算 PIR
        ↓
逐帧 `pir_valid_primary`
        ↓
构造连续 left / right / binocular PIR 时间序列
        ↓
按照科学问题定义 trial / probe / time-on-task 分析单元
        ↓
在对应分析单元内检查 coverage 与时间代表性
        ↓
进入正式模型
```

30 s、60 s、probe 前 10 s/20 s/30 s/60 s 等窗口长度属于分析尺度，不属于最底层数据清洗规则。窗口长度应根据具体心理学问题决定，而不是为了适配 QC 人为固定。

## 7. 正式报告可直接使用的方法文本

### 7.1 数据预处理与 PIR 构建

近红外眼部视频首先通过眼部检测与追踪获得眼睛感兴趣区域（region of interest，ROI），随后采用 RITnet 对眼部图像进行四分类语义分割，将像素划分为背景、巩膜、虹膜和瞳孔。基于分割结果，对瞳孔及外虹膜主体轮廓进行椭圆拟合。外虹膜定义为可见虹膜组织与中央瞳孔区域的联合区域，以恢复完整的虹膜外边界。瞳孔与外虹膜的几何平均直径分别定义为椭圆两轴乘积平方根，最终计算瞳孔/虹膜直径比（pupil-to-iris diameter ratio，PIR）作为尺度归一化后的瞳孔指标。

### 7.2 逐帧质量筛选

逐帧 PIR 的主分析纳入依据以瞳孔—虹膜主体几何关系为核心。仅当瞳孔椭圆与外虹膜椭圆均可有效拟合、瞳孔中心位于外虹膜主体轮廓内部或边界上、外虹膜几何平均直径大于瞳孔几何平均直径，且 PIR 为有限数值时，该眼该时间点被定义为主分析有效帧。无效帧作为缺失数据处理，不置零、不进行强制插值，也不据此自动删除对应行为试次、整只眼、实验 Block 或被试。

生产阶段曾采用较保守的整张分割掩膜触边（whole-mask edge）规则，即只要瞳孔或外虹膜的任意分割像素接触分析图像边界即判为无效。后续质量审计发现，大量此类触边来自眼球主体轮廓之外的孤立误分割小块，而 PIR 的椭圆拟合主要依赖最大主体轮廓。因此正式主分析不再将 whole-mask edge 单独作为硬性剔除条件，而将其保留为质量诊断变量。原始严格规则同时作为敏感性分析保留，以评估正式结果对数据筛选定义的稳健性。

### 7.3 双眼与分析单元处理

左右眼首先独立完成逐帧质量判断。某一时间点两眼均有效时，保留两眼信息并在完成眼别基线校正后构造双眼指标；仅一眼有效时由该眼提供该时间点的 PIR；两眼均无效时该时间点记为缺失。所有左右眼原始轨道均被保留用于敏感性分析。对于 trial、probe 前时间窗或 time-on-task 等后续分析，再根据该具体分析单元内有效 PIR 的覆盖率和时间代表性判断该单元能否稳定估计目标特征。覆盖率标准不参与最底层逐帧有效性的定义。

## 8. 当前本地数据状态与不可覆盖原则

截至本规则形成时，AMD 本地正式 RITnet full-class CSV、原始 NIR 输出、Behavior 数据和既有 alignment 均未因本轮 QC 审计而修改。

当前已有输出主要属于：

```text
01_qc/
02_standardization/
03_time_on_task/coverage_calibration/
04_frame_quality_audit/
```

它们是 QC、测量结构和方法校准结果，不等于已经生成了最终“清洗后正式分析主表”。

后续正式数据物化（materialization，按照冻结规则生成可直接用于统计模型的派生数据文件）必须遵循：

```text
冻结 production full-class CSV：只读
        ↓
读取现有几何字段和 PIR
        ↓
新增 `pir_valid_primary` / `pir_valid_strict`
        ↓
生成 left/right/binocular 连续分析序列
        ↓
另存到正式 analysis 输出目录
```

不得覆盖、重写或删除原 production CSV。这样可以随时从同一原始提取结果重新生成不同版本的分析数据，并保持完整 provenance（数据来源与处理过程可追溯性）。

## 9. 当前决策状态

已冻结：

1. PIR 的计算公式和 pupil/iris 主体几何定义；
2. 主分析使用 relaxed frame-level validity；
3. whole-mask edge 降级为 QC / sensitivity，而不是 primary hard exclusion；
4. 旧 `fullclass_normalization_valid + finite PIR` 保留为 strict sensitivity；
5. 左右眼先逐帧独立判断，再构造连续 binocular PIR；
6. 不因局部单眼缺失自动删除被试、Block 或 Behavior trial；
7. 30 s / 60 s coverage 不属于底层数据清洗规则。

尚未物化：

1. 正式 `pir_valid_primary` / `pir_valid_strict` 派生字段；
2. 最终 left/right/binocular 连续 PIR 主分析表；
3. 针对 trial、probe、time-on-task 各分析问题的具体分析单元和 coverage 规则。

因此下一步不再继续扩展基础 QC，而应生成正式派生分析数据层，并进入 time-on-task、Behavior 与 Probe 的正式统计分析。
