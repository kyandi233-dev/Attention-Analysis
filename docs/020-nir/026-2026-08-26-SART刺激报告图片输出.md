# SART 刺激报告图片输出

> 2026-08-26｜分支：`amd-DirectML`｜实现：`stimulus-visual-v1.2`。

本文件补充 `025-2026-08-26-SART刺激视觉协变量重建.md`。数值视觉协变量仍由 `stimulus_visual_properties.csv` 保存；v1.2 额外输出可直接用于实验报告、方法示意和附录的重建图片。

## 1. 为什么需要单独输出图片

只有 CSV 能用于统计控制，但不方便在报告中说明被试实际看到了什么。因此 v1.2 同时保存：

1. 27 个 `水果身份 × 80/100/120%` 条件的完整重建屏幕；
2. 正式 `刺激.png` 背景的完整屏幕重建；
3. `刺激.png + 掩蔽刺激.png` 的完整 mask 屏幕重建；
4. 27 条件的完整屏幕总览图；
5. 27 条件的中央固定 ROI 总览图，便于在报告中看清水果大小和形态差异。

## 2. 完整屏幕图片

每个正式条件输出一张 2880×1920 PNG，严格使用北京正式 Surface Pro display profile：

```text
D:\_AttentionData\Beijing-NIR\analysis\nir-behavior-v1\
└── stimulus_visual_rendered\
    ├── references\
    │   ├── 00_background_screen.png
    │   └── 00_mask_screen.png
    └── conditions\
        ├── 01_mango_size080.png
        ├── 01_mango_size100.png
        ├── 01_mango_size120.png
        ├── ...
        └── 09_no_go_size120.png
```

这些 `conditions/*.png` 是完整实验窗口重建，不是裁剪后的水果截图。画面包括：

```text
2880×1920 Surface Pro canvas
+ BG_COLOR 填充区
+ 按 win.size[0] 自适应缩放的 刺激.png
+ 按 BASE_SIZE × stimulus_size 缩放并位于 (0,-20) 的水果
```

因此可直接用来展示“正式 trial 实际视觉画面”。

## 3. 报告用总览图

另外输出：

```text
stimulus_visual_overview_full.png
stimulus_visual_overview_central.png
```

`overview_full`：9 行水果 × 3 列大小的完整屏幕缩略图。它适合展示不同条件在完整 Surface Pro 画面中所占比例。

`overview_central`：仍然是 9×3 条件，但只显示与视觉协变量一致的固定中央 ROI。它不是正式呈现画面的替代品，而是为了在论文/报告有限版面中更容易观察 80/100/120% 的大小差异和水果本身的视觉差异。

推荐报告正文优先使用中央总览图；方法部分或附录再选择 1–3 张完整屏幕条件图作为实际呈现示例。

## 4. 与 CSV/manifest 的关系

完整 PNG 不改变 `stimulus_visual_properties.csv` 的数值 schema。`stimulus_visual_manifest.json` 会新增 `report_images`，记录：

- 27 张完整条件 PNG 的文件路径、SHA256、尺寸；
- 背景与 mask 完整屏幕 PNG；
- 两张总览图的路径与 SHA256；
- 完整条件图数量和正式分辨率。

因此图片与数值表来自同一套素材、同一 display profile、同一 config digest，不需要人工截图后再猜对应条件。

## 5. 运行

更新 AMD 分支后：

```powershell
$env:PYTHONPATH = "src"
python -m pytest tests/test_stimulus_visual.py tests/test_stimulus_visual_report.py -q
```

测试通过后重新运行：

```powershell
python scripts/build_stimulus_visual_table.py
```

若无法自动发现 FocusWave 素材：

```powershell
python scripts/build_stimulus_visual_table.py `
  --materials-dir "D:\AAAWORK\07-竞赛\厚璨杯\020-Experiment\_AttentionTest\01-MainProgram\素材"
```

同一次运行会同时更新 CSV、manifest、27 张完整 PNG、2 张 reference PNG 和 2 张 overview PNG。
