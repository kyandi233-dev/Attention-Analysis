# 210｜PIR 六条 gate 失败原因 QC 结果

> 2026-08-26｜当前北京 NIR 44 人 exploratory/development cohort。本文记录 `029-2026-08-26-PIR有效性与usable筛选定义.md` 所冻结的 6 条 `fullclass_normalization_valid` gate 在真实 cohort 中的失败分布、重点异常模式与正式报告可引用结果。本文是**数据筛选结果记录**，不是新增筛选阈值。

## 1. 本文与 029 的关系

- `029`：规定 PIR 的正式帧级数据筛选条件，回答“什么样的一帧 PIR 才算 usable”。
- `210`：记录这些筛选条件在当前 44 人 cohort 中实际筛掉了什么、主要因为什么失败。

当前正式 frame-level PIR usable 定义仍为：

```text
六条 normalization gate 全部通过
AND
PIR 为 finite 数值
```

本文不修改任何 gate，不新增 subject / eye / Block 的硬排除标准。

## 2. 数据与运行完整性

本轮基于 44 人正式 full-class NIR 数据进行逐 `subject × eye × Block` gate failure 审计。

- 44/44 个 subject 成功读取；
- 共得到 176 条 `subject × eye × Block` 记录；
- `normalization_gate_mismatch_fraction` 最大值为 **0.00000000**；
- 即：逐帧重新根据六条 gate 计算出的 normalization validity 与生产数据中的 `fullclass_normalization_valid` 完全一致；
- 脚本返回码为 0；
- 仅出现源 CSV 混合类型导致的 pandas `DtypeWarning`，未发生读取或计算失败。

因此，029 中记录的六条 gate 可以被视为当前正式数据中 `fullclass_normalization_valid` 的真实、完整判定逻辑，而不是近似解释。

### 3.1 分布层面的解释

从中位数看，大多数 eye×Block 的六类 gate failure 比例都较低；但分布右尾明显，说明少数 eye×Block 存在严重、局部的结构失效。

其中：

- `iris outer edge failure` 的 P90 已达到约 0.517、P95 约 0.705，说明“外虹膜结构触及 analysis ROI 边缘”是 cohort 中较常见的高失败来源之一；
- `pupil center-in-iris failure` 的 P95 约 0.569，也存在明显长尾；
- `pupil fit`、`iris larger-than-pupil` 在多数记录中较低，但少数记录可接近 1，提示部分 eye×Block 是整体几何拟合/结构关系失败，而不是简单边缘截断。

这些分布用于描述筛选过程，不自动转化为新的排除阈值。

## 5. 已知低 usable 记录的主导失败原因

### sub-171

B1/B2 的 `frame_left` 主要由两个 ROI edge gate 导致：

- B1 pupil edge failure = 0.982105
- B1 iris outer edge failure = 0.990965
- B2 pupil edge failure = 0.966347
- B2 iris outer edge failure = 0.972642

其余四类 gate 相对较低。因此 sub-171 左眼极低 usable 的主要含义是：**RITnet 分割出的 pupil / iris outer 长期触及 analysis ROI 边缘，导致几何尺度不可靠。**

### sub-153

B1/B2 `frame_left` 同样主要由两个 edge gate 导致：

- B1 pupil / iris outer edge failure = 0.901933 / 0.971088
- B2 pupil / iris outer edge failure = 0.965282 / 0.988329

B2 的 center gate failure 也有一定贡献（0.290183）。

### sub-165

异常主要集中在 B2 `frame_left`：

- pupil edge failure = 0.967774
- iris outer edge failure = 0.981821
- center failure = 0.084460

说明这是较明显的**单 Block、单眼局部结构问题**。

### sub-047

B1/B2 `frame_left` 是多 gate 同时失败，而不是单纯 edge 问题：

- B1 pupil fit / center / iris-larger failure = 0.961075 / 0.969248 / 0.961818
- B2 pupil fit / center / iris-larger failure = 0.844054 / 0.867349 / 0.845722
- iris outer fit failure 也明显偏高

因此 sub-047 左眼属于更广泛的 pupil–iris 几何拟合/结构关系异常。

### sub-150

B2 双眼均受 pupil fit、pupil center、iris larger-than-pupil 影响：

- B2 left = 0.810339 / 0.840584 / 0.810888
- B2 right = 0.825360 / 0.857751 / 0.825883

此外 B2 left 的 iris outer fit failure = 0.589759。

因此 sub-150 B2 更接近**双眼、同 Block 的结构质量问题**，后续具体分析中该 Block 很可能有大量窗口因 usable coverage 不足而自然无法进入模型，但这仍不等于整名被试全局排除。

### 其他局部模式

- sub-035 B1/B2 frame_right：主要为 iris outer edge failure；
- sub-036 B1 frame_right：主要为 pupil fit、center 和 iris diameter-order failure；
- sub-163 B1/B2 frame_left：edge gate 较高；
- sub-176 较低 usable：主要与 pupil fit / pupil center 有关，而不是 edge gate。

## 8. 正式报告如何使用这些结果

### 8.1 方法部分

方法部分引用 029，不需要把本页所有异常被试写进去。应写清：

- PIR 的构建方式；
- 六条 normalization gate；
- finite 数值检查；
- 无效帧不置零、不强行插补；
- 不按单个坏帧直接删除整名被试；
- 后续按具体分析窗口 usable coverage 做第二层筛选。

### 8.2 数据质量 / 样本筛选结果部分

当前 44 人 exploratory cohort 可写成：

> 44 名被试的 NIR 与行为数据均成功读取，共形成 176 个 subject×eye×Block NIR 单元。逐帧重新依据六项 pupil–iris 结构门控计算的 normalization validity 与生产数据中记录的 `fullclass_normalization_valid` 完全一致，最大 mismatch fraction 为 0。质量异常主要呈现为局部单眼或单 Block 的 gate failure，且不同记录的失败机制并不一致：部分记录以 pupil/iris outer 触及 analysis ROI 边缘为主，部分记录则表现为瞳孔或虹膜椭圆拟合及 pupil–iris 几何关系异常。因此本研究未依据单个 eye×Block 的总体可用率对被试做全局硬排除，而是在保留原始 subject/eye/Block 结构的基础上，将未通过帧级结构门控的 PIR 视为 unavailable，并在后续具体分析中依据预先设定的时间窗有效覆盖率进一步筛选分析单元。

当前 44 人只是 exploratory/development cohort；最终约 116 人数据完成后，上述数量和 gate failure 分布必须重新计算，不能直接沿用当前数值。

## 9. 禁止误读

以下表述均不正确：

- “PIR usable 低就删除被试”；
- “ROI clipped 高就是 normalization invalid”；
- “所有低 usable 都是 RITnet 没找到瞳孔”；
- “六条 gate failure fraction 相加就是总失败率”；
- “当前 44 人的 P5/P10 可以直接作为未来正式样本排除阈值”。

正确理解是：六条 gate 定义**逐帧结构有效性**；gate failure 分布只用于解释数据质量；最终 trial/probe/time-bin 的纳入仍由对应分析预先冻结的 coverage 条件决定。
