> 2026-08-26（Asia/Shanghai）｜科学基线：`amd-DirectML`；当前进一步融合分析开发分支：`analysis/multimodal-integration`。本文件承接 `027-44人全量分析数据边界与资料清单.md`，用于记录当前 44 人 exploratory/development cohort 的正式分析路线、输出目录、行为解释边界、阶段决策与持续进度。每完成一个具体步骤，均应更新本文件中的“进度记录”和“已冻结/未冻结项”，避免分析规则只存在于对话中。

## 1. 当前阶段定位

北京正式实验最终计划样本为 116 人；当前本机已经有 44 名被试完成 `ritnet-fullclass-v1.2-fast-qc` full-class NIR 处理。44 人阶段的首要作用不是提前形成最终科学结论，而是：

1. 验证 cohort-level downstream pipeline 能稳定扩展到多人；
2. 描述 NIR 数据质量和群体分布；
3. 确定左右眼测量结构；
4. 比较 PIR 标准化方案；
5. 确定合理的 QC、时间窗和基础模型结构；
6. 形成可在最终 116 人中直接复用、并在正式确认阶段尽量不再因结果好坏而改变的分析政策。

因此，44 人中的显著性结果、某个看起来“最好”的 cutoff 或窗口，都不能自动升级为最终 116 人结论。当前阶段允许冻结的是经过 QC、测量结构和稳健性支持的分析规则，而不是科学效应本身。

## 5. Phase 1｜Cohort discovery 与 QC

### 5.1 Cohort preflight

第一步建立真实的 cohort 完整性表，而不是直接解除 `subjects.include=[sub-031]` 后盲跑所有被试。

首批输出：

```text
00_inventory/cohort_discovery.csv
00_inventory/cohort_preflight_summary.json
```

`cohort_discovery.csv` 一行一名被试，至少记录：

- subject；
- production full-class source path；
- completion / extension version；
- full-class CSV SHA256；
- Behavior B1/B2 是否存在；
- B1/B2 trial 数；
- probe 数；
- B1-left / B1-right / B2-left / B2-right 是否存在；
- 每个 eye×block NIR rows；
- duplicate/alternative run；
- schema/header 差异；
- alignment 是否已经完成；
- preflight error/warning。

这一层只回答“有什么数据”和“输入是否可运行”，不设质量排除门。

### 5.2 Subject×eye×block QC

核心 QC 单位固定为：

```text
subject × eye × block
```

44 人理论最多 176 个 QC 单元。输出：

```text
01_qc/subject_eye_block_qc.csv
01_qc/subject_qc.csv
01_qc/cohort_anomaly_flags.csv
```

每个 subject×eye×block 至少统计：

**时间/覆盖**

- n_nir_rows；
- observed duration；
- sampling_rate_hz；
- rows/sec；
- internal coverage；
- max temporal gap；
- zero-NIR / long-gap 描述；
- 是否整段 eye/block 缺失。

**NIR/segmentation QC**

- `ritnet_found_fraction`；
- `roi_clipped_fraction`；
- ocular component / fragmentation 指标；
- 关键 full-class 字段 finite fraction。

**PIR**

仅 `fullclass_normalization_valid=True` 进入 PIR 数值描述，计算：

- valid fraction；
- median / mean；
- MAD / IQR / SD；
- P01/P05/P10/P90/P95/P99；
- min/max；
- robust slope；
- successive-difference MAD / rate-MAD。

**OAR**

对 `fullclass_ocular_aperture_ratio_median` 计算相同类型的连续描述，但 OAR 仍只解释为 NIR visible ocular aperture / eye-openness auxiliary feature，不定义 blink、EAR、closed state 或 PERCLOS。

### 5.3 QC flag 原则

Phase 1 可以产生例如：

```text
missing_eye_block
low_pir_availability_candidate
long_gap_candidate
sampling_irregular_candidate
fragmentation_candidate
pir_distribution_extreme_candidate
oar_distribution_extreme_candidate
left_right_discordance_candidate
```

但这些都是 review/candidate flags。44 人阶段先标记、排序和可视化，不根据某一个经验阈值自动删除 subject 或 eye。

## 6. Phase 2｜左右眼测量结构与 PIR 标准化

### 6.1 左右眼不能只看相关

需要同时评估：

- left/right Pearson 与 Spearman correlation；
- subject×block median offset；
- absolute difference；
- Bland–Altman agreement；
- ICC（在适用且定义明确时）；
- left/right MAD、IQR、valid fraction、gap 的差异；
- Block1/Block2 中 subject×eye offset 是否稳定。

目标是回答：

1. 左右眼是否同步变化？
2. 是否存在稳定 subject×eye baseline offset？
3. 哪些人明显单眼低质量？
4. future analysis 更适合双眼平均、双眼重复测量、wide predictors、subject×eye centering 还是 single-eye fallback？

在这一阶段完成前不提前平均左右眼。

### 6.2 标准化方案并行比较

至少保留四个版本：

```text
A. raw PIR
B. subject×eye median-centered PIR
C. subject×eye robust z PIR
D. block-specific centering（仅作为必要时的 sensitivity candidate）
```

robust z 候选定义：

```text
(PIR - subject×eye median) / (1.4826 × subject×eye MAD)
```

需先检查 MAD 近零、极端分布和稳定性。Block-specific centering 不能默认作为主方案，因为它可能消除真实 Block1→Block2 session-level shift。

正式建模优先考虑 within/between decomposition：

```text
PIR_between = subject×eye session baseline
PIR_within  = current PIR - PIR_between
```

raw、centered 和 standardized 轨均保留，不静默覆盖。

## 7. Phase 3｜描述性分布与 time-on-task

先做纯 NIR，不使用 commission/omission/probe outcome 选择分析规则。

主要时间结构：

- Block1 vs Block2；
- non-overlapping 60-s fixed bins；
- 30-s bins 作为 sensitivity；
- normalized block time 0–1；
- 必要时再考虑 nonlinear trend / GAM(M)。

每个时间单元分析 PIR/OAR：

- level；
- MAD/IQR/SD；
- slope；
- diffMAD / diff-rate MAD。

不把高重叠 sliding windows 当独立样本做普通 t-test。

## 8. Phase 4｜行为与 Probe

### 8.1 `omission` 不是单一行为类型

程序原始字段 `omission=1` 必须永久保留，但不能直接解释成同质的 sustained-attention lapse。根据 `023-2026-08-25-sub031行为按键审计.md` 和当前 `behavior_qc.py`，至少已存在：

```text
program_raw_omission
├── clean_omission_candidate
├── prestimulus-associated_omission
└── carryover-associated / ambiguous_omission_candidate
```

其中：

- `prestimulus-associated_omission`：当前 Go trial 在 onset 前极短时间已经出现按键，但程序仍记录 `response=0, omission=1`；
- `carryover-associated / ambiguous omission`：上一 trial 第二次按键非常靠近当前 onset，当前 trial 随后没有正式 response；
- `clean_omission_candidate` 只能表示当前已知 QC 证据中未见上述模式，不能被过度解释为已经证明的纯注意漏失；
- cohort 44 行为审计可能发现更多可重复序列类型，届时应增加非破坏性 subtype flag，而不是改写原始程序评分。

此外，anticipatory motor pattern 本身可能是一类有心理意义的行为表型，而不仅是需要删除的脏数据。

因此 Go trial 的分析至少分三层：

1. raw program scoring：原始 omission vs response；
2. QC-aware omission analysis：clean / prestimulus-associated / carryover-associated 等 subtype 或敏感性模型；
3. exploratory motor-timing phenotype：anticipatory / multiple-press / carry-over 模式本身与 NIR 的关系。

### 8.2 No-Go / Go / RT 分开

No-Go：

```text
commission vs correct inhibition
→ logistic mixed model
```

Go：

```text
raw omission / omission subtype vs response
→ logistic / categorical mixed model，具体形式由 44 人 subtype 频数决定
```

有效 Go RT：

```text
RT / logRT
→ LMM 或 robust mixed model
```

不能把 Go 与 No-Go 压缩成单一 accuracy model。

### 8.3 Trial 时间窗

保留 frozen schema 中全部 candidate windows，但按科学问题分层：

- event/PLR：`pre_200ms`, `post_200ms`, `post_200_1150ms`；
- immediate precursor：pre-1/3/5 s；
- tonic state：pre-10/20/30/60 s。

44 人阶段的窗口选择优先依据 coverage、reliability 和 construct timescale，而不是哪个窗口 p 值最好看。

### 8.4 Probe

Q1 四分类 attention state：先检查每类 probe 频数和 subject coverage，再决定 multinomial/categorical mixed model；不把 1–4 当线性连续值。

Q2 vigilance 1–4：使用 ordinal mixed model 候选。

Probe 继续分析 10/20/30/60 s，并构建 `-60~0 s`、5-s bins trajectory；优先整体 `state × time` / `vigilance × time`，而不是每个 bin 独立检验。

## 9. 视觉协变量

事件相关 PIR 模型继续使用 versioned `stimulus_visual_properties.csv`。至少评估：

- current central relative luminance；
- current central RMS contrast；
- mask→stimulus central luminance step；
- previous-trial visual properties。

但控制变量必须符合时间因果关系：current stimulus 不能被解释为造成 onset 前的 pre-state PIR；previous visual history 对 pre-state / event-adjacent pupil 更重要。所有高度相关视觉变量先做 correlation/VIF/condition-number 审计，不机械全部塞入同一个模型。

## 10. Phase 5｜Robustness / ML

Robustness 至少比较：

- raw vs centered vs robust-z PIR；
- left vs right 与后续冻结的 eye policy；
- candidate QC flags inclusion/exclusion；
- gap/coverage sensitivity；
- clipped included/excluded；
- 10/20/30/60 s window sensitivity；
- raw behavior scoring vs QC-aware omission/anticipatory sensitivity。

机器学习仅作为 prototype：Elastic Net / Random Forest / XGBoost 为优先候选。所有 train/test split 必须 group by subject，禁止同一个被试的 trial/probe 同时进入训练与测试。

若目标是 retrospective explanatory analysis，可以用整段 session baseline；若目标是 prospective/online prediction，subject baseline 只能使用 calibration period 或截至当前时刻的历史数据，不能使用未来数据计算标准化。
