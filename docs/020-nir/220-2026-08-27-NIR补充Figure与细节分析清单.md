# 220｜NIR Supplementary Figure 与细节分析清单

> 2026-08-27｜本文件补充 [219-2026-08-27-NIR论文级Figure体系与补充分析实现.md](219-2026-08-27-NIR论文级Figure体系与补充分析实现.md)。主 Figure 1–10 保持论文主线清晰；不能塞进主图但又不能丢失的分析统一进入 Supplementary Figure。
>
> 当前 NIR/PIR 数值已知错误，因此这些图仍是 validation-only。全部由 Python/Matplotlib 代码生成。

## 为什么需要 Supplementary Figure

主 Figure 1–10 已经覆盖：全实验 PIR、Block/time-on-task、trial outcome、错误前兆、Probe、视觉控制、个体差异、feature structure、QC 和 robustness。但如果把所有细节都压进主图，会重新出现图例过大、panel 太密、字体缩小、信息层次不清的问题。

因此以下四类细节单独保存。

## Figure S1｜错误前动态细节

```text
FigureS01_error_dynamics
```

四个 panel：

- A：No-Go correct inhibition vs commission 前的连续 `pir_sd` trajectory；
- B：Go correct reference / clean omission / ambiguous omission 前的连续 `pir_sd` trajectory；
- C：No-Go 之前若干正确 Go trial 的 RT trajectory；
- D：No-Go 之前若干 trial 的 PIR MAD trajectory。

主 Figure 4 强调 PIR level；S1 专门保留 variability 与离散行为前兆。

## Figure S2｜Probe 前客观行为多时间窗

```text
FigureS02_probe_objective_behavior
```

按 `probe_response` raw option 和 Block 区分，展示：

```text
pre-10 / 20 / 30 / 60 s
```

内的：

- Go RT-CV；
- commission rate；
- program omission rate；
- anticipatory candidate rate。

底层 `probe_behavior_multiscale` 仍同时保留 ambiguous omission 等字段；主图不重复塞入所有行为指标。

## Figure S3｜Probe 回答时间

```text
FigureS03_probe_response_times
```

分别展示：

- `probe_rt` × `probe_response` × Block；
- `probe_vigilance_rt` × `probe_response` × Block。

这两个 RT 用于描述状态判断/回答过程，不与 SART Go RT 混为一个指标。

## Figure S4｜刺激 identity × size 细节

```text
FigureS04_stimulus_identity_size
```

以 stimulus identity 为行、stimulus size 为列，分别展示：

- pre-trial PIR；
- central relative luminance；
- central RMS contrast；
- visible-area fraction。

该图用于检查视觉刺激层面的 PLR/confound 结构；正式解释重点不是“哪个水果显著”，而是确认视觉属性是否需要进入 pupil 模型。

## 与旧 diagnostic figures 的关系

历史 `fig00...fig16...` 工程图继续保留在原 `12_pipeline_validation/figures/` 路径，以避免改变已有 provenance 和外部引用；它们被视为 diagnostic outputs。新的 manuscript Figure 使用：

```text
figures/publication/
figures/publication/supplementary/
```

因此不需要删除任何旧图，也不会再把旧图的尺寸、DPI 或排版当成论文标准。
