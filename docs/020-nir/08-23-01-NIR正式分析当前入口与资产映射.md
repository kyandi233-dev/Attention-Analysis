## 数据发现规则

正式原始数据位于两个逻辑目录 `正式实验` 与 `Data`，但两块外接存储设备的 Windows 盘符可能在 `E:` / `F:` 之间变化。正式 runtime 因此同时声明：

```text
E:/正式实验
F:/正式实验
E:/Data
F:/Data
```

批处理会忽略不存在的候选根，并在所有有效根中发现 NIR 视频。如果同一被试的视频同时出现在多个有效根，批处理会报 duplicate，而不是静默选择其中一份。

## 当前运行命令

```cmd
git switch amd-DirectML
git pull
cd /d <repo>\runtime\nir-formal
conda activate D:\CondaEnvs\nir-amd
python run_pipeline.py check-env
python run_pipeline.py discover --formal-only
python run_formal_batch.py --dry-run
python run_formal_batch.py
```

单被试优先直接给视频路径，避免把可变盘符写进固定命令：

```cmd
python run_pipeline.py formal --video "<实际盘符>:\<数据根>\sub-033_\nir\sub-033_nir.avi" --device 0
```

如果使用支持 `--subject/--root` 的诊断入口，则 `<实际盘符>:\<数据根>` 必须按当次挂载状态选择，不把 `E:` 或 `F:` 写成科研口径的一部分。
