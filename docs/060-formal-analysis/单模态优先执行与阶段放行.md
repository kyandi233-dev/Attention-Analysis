方法权威为 FocusWave-Formal-Analysis 的 1.16.4–1.16.10；本页说明代码执行和产物，不能替代上游测量决策。

| 阶段 | 跟踪 | 本阶段提供的能力 | 科学放行边界 |
|---|---|---|---|
| 1 | #66 | 单模态 Q1-blind 分布、覆盖、表示差异与变量角色审核 | 有限数值不代表 QC/效度；不生成正式预测 |
| 2 | #67 | 冻结后的单特征及科学模态独立预测 | 该模态自己的测量冻结和 Task B 状态通过后，不等待无关模态 |

## 阶段 1：可立即调用的审核入口

安装仓库所需依赖并确保本 checkout 的 `src` 在 Python 路径（例如 `pip install -e .`）。从仓库根运行：

```powershell
python scripts/single_modality_feature_review.py --input <权威probe表.csv> --modality behavior --output-root <仓库外新的审核目录>
```

其他可选科学模态为 `ocular`、`movement`、`cardiopulmonary`。输入必须包含 `participant_group_id/session_id/block_id/probe_event_id`，每个探针一行，同一场次只能属于一个参与者。缺少本模态候选列会显示 source-column-missing，不要求无关设备存在；不得用含多条 signal/track/buffer/bin 的 NIR 审计长表冒充一行一探针宽表。

默认目录 `configs/single_modality_features_v1.yaml` 记录当前有限候选与变量角色。Behavior 主集为 RT level（mean/median 待定）+ CV + Theil-Sen RT trend + raw Go omission + commission；SD/MAD/IQR、d-prime 和细分 omission 保留描述/敏感性角色。RGB 的 blink 属 Ocular，visible movement 属 Movement，曝光/方向辅助量不升级为主变量。

NIR G1 审计仍通过 #44/1.16.3 的现有 measurement-audit 入口运行。尚未冻结的 pupil 最终宽表表示和心肺变量在本目录中明确留空并展示待定，不恢复旧的唯一几何信号/旧 slope 为最终定义。真实测量冻结后更新候选目录及来源版本，再接入阶段 2。

输出三个文件：

- `feature_review.csv`：报告变量名、角色、有限值/缺失/坏字符串/非有限值分轨、参与者宏平均可用比例、描述分位数；不含参与者行级键。
- `representation_contrasts.csv`：同一维度候选的成对数值差异；只描述，不按差异或覆盖自动筛选。
- `modality_release.json`：各维度冻结状态、已具备证据的表示、仍缺的条件、输入/目录/输出哈希。

这里的 coverage 只指有限值覆盖，不等价于 source/alignment/QC/estimability。pooled-probe 分布是描述统计，不能代替参与者等权预测性能；`participant_macro_finite_fraction` 单独表达每位参与者等权的覆盖情况。

## 显式测量决策

审核不会自动选择 mean/median 或判定测量合格。上游依据正式测量证据作出决定后，提供 JSON 文件并加 `--decisions <文件>`。该文件必须绑定上一次审核的 source/catalog SHA256，不能用旧证据静默选择新数据。格式示例：

```json
{
  "source_sha256": "从modality_release.json取得",
  "catalog_sha256": "从modality_release.json取得",
  "modality": "movement",
  "decisions": {
    "movement_visible_level": {
      "measurement_status": "qualified",
      "selected_column": "body_motion_energy_median",
      "evidence_refs": ["实际测量审核和Formal决定的版本化位置"]
    }
  }
}
```

可用状态为 pending/qualified/rejected；qualified 和 rejected 都需要证据。只能选择目录中的主候选，不能选择描述/QC 字段、增加 outer-test 分数作为选取依据、移除已有预处理依赖或篡改已知设备依赖。同一科学维度仅选择一个表示。代码验证证据引用和合同一致性，不能替代对引用内容的科学审查。

一个维度通过不代表完整模态已通过；完整模态所需的各维度均完成后才标记表示冻结。源列损坏/全缺失会另记执行阻断，不会把科学判断自动改成“无效”。即使表示冻结，本审核仍令 `supervised_execution_authorized=false`，下一步是 Task B probe 级 QC、真实 schema 和参与者足够的训练链检查。
