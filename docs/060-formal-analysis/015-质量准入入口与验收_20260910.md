## 入口

在仓库根目录的 PowerShell 中运行：

```powershell
$env:PYTHONPATH = 'src'
python scripts/multimodal_fusion_analysis.py --quality-only --config configs/multimodal_fusion.yaml --paths-config '你的机器路径注册表.yaml' --run-id quality-admission-v1-20260910
```

机器注册表沿用 `multimodal_fusion_data_root` 与 `multimodal_fusion_output_root`。
相对输入路径来自融合配置 `inputs`，未配置时复用既有加载器默认入口。
输出为 `<multimodal_fusion_output_root>/<run-id>/quality_admission/`，已有 run 拒绝覆盖。
本入口在导入模型 runner 之前返回，可独立运行。

## 输出字段与规则

| 文件 | 内容 |
|---|---|
| `probe_quality.csv` | 正式 probe 主键、参与者组、模态、特征；`source_present`、`source_readable`、`aligned`、`native_qc_valid`、`feature_computable`、`inclusion_reason`、来源/质量/对齐依据；只在有效时保留数值 |
| `feature_admission.csv` | 正式 probe 数、机会数、可计算数、三种覆盖率、不同值数、零方差、地板/天花板复核标记、`main_candidate` 与原因 |
| `modality_availability.csv` | 各模态真实源数、可读数、有源且可读对齐数、正式分母及模态可用率 |
| `candidate_features.json` | 通过输入质量门的各模态特征名；供下一阶段显式读取，不自动启动或改写历史模型 |
| `analysis_sets.csv` | 保留行为全部 probe，逐组合给出 `analysis_set_id`、`included` 和集合规则 |
| `redundancy_review.csv` | 配置明确声明的同测量家族中，Spearman 秩相关绝对值 ≥ .90 的成对复核提醒；不自动删除 |
| `summary.json` | 规则版本、阈值、代码提交及修改状态、配置/输入摘要、输入路径、缺失输入、各集合 probe/场次/参与者数、限制与 `models_trained=false` |

三种覆盖率分别为：有源可读且对齐数/正式 probe 数；可计算数/有源可读且对齐数；可计算数/正式 probe 数。
没有计算机会时，特征可计算覆盖率为空，不能视为通过。门槛为未四舍五入的覆盖率 ≥ .80，且至少 3 个不同有限有效值。
列缺失、全缺失、零方差均有独立原因。比例型指标至少 95% 观测 ≤ 0.02 或 ≥ 0.98 时仅标记复核；不会因为该标记自动删除。

质量控制（quality control [QC]）复用已有字段：行为 `rt_cv_status`、`sdt_status` 等；近红外 `n_nir_rows` 与特征原生有效观测数；可见光 `rgb_source_status`；毫米波 `mmwave_observed` 与 `mmwave_loadable`。
没有明确原生 QC 门时记录 `not_explicitly_gated`，依赖上游有限值语义，不增加生理百分比阈值。已有行或单个有限特征不作为传感器源存在的替代证据。
毫米波 E 批次未导出 Block 起止时间时，仅在明确 `window_boundary_source=probe_primary_30s` 时沿用行为正式窗口；仍检查已有窗口长度和 probe 前边界。有明确 Block 边界时必须通过边界检查。
空/重复/非法键与身份冲突停止执行；缺模态表保留行为分母。非正式 probe 行数在清单单独计数。

## 集合与科学边界

本次 `analysis_sets.csv` 输出严格完整观测集合：每个所需模态至少存在一个准入特征，且该模态所有准入特征在该 probe 均可计算。无准入特征的模态不能产生完整集合。未插补任何值。
这是可复核的保守集合，不自动冻结后续允许少量特征缺失的建模集合；后续若使用训练内插补，必须显式记录新的集合与缺失策略。配对模型比较应统一采用所比较模型所需模态的同一个集合，不能直接跨本表不同组合集合比较性能。
全数据输入清单不拟合预处理；训练阶段仍需在每个训练折内部重新拟合插补、标准化和数据驱动筛选。不能将此处全数据分布审查当作独立测试结果。
毫米波生理质量阈值与科学放行仍由权威合同决定，`main_candidate` 仅表示本层输入质量通过。

监督学习行为配置使用 `clean_go_omission_rate` 与 `timing_ambiguous_go_omission_rate`。
`raw_go_omission_rate` 为总遗漏，`omission_rate` 为其兼容别名；原始描述性表继续保留。模型特征解析器会拒绝总量/别名重复及总量加两个组成的代数冗余。
