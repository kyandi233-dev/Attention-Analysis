# NIR 专用 YOLO 眼框离线标注指南

> 2026-08-17 Asia/Shanghai｜本文件说明如何在无网络环境中制作 `eye` 单类别 YOLO 数据集；标注阶段不需要连接正式数据分析管线。

## 1. 标注目标

每张原始 NIR 帧标注两只眼的矩形框：

- 类别只有一个：`eye`；
- 左眼和右眼不分成两个类别；
- 框包含眼裂、上下眼睑和少量眼周区域；
- 不要只框瞳孔；
- 不要把大片鼻梁、脸颊或额头包含进去；
- 闭眼仍然标眼睛所在区域，只要眼睛位置可判断；
- 完全没有眼睛的帧不标框，但要在清单中记录为 `no_eye`。

## 2. 推荐的离线目录

标注包可以放在任何硬盘，建议使用如下结构：

```text
nir-eye-dataset-v1/
├── images_raw/                 # 原始抽帧图，不覆盖
├── images/                     # 交给标注工具的图片
├── labels_yolo/                # 与图片同名的 .txt
├── manifests/
│   ├── frames.csv              # 抽帧清单
│   ├── annotations.csv         # 标注状态和人工备注
│   └── split_subject.csv       # train/val/test 被试划分
├── previews/                   # 画框预览图
└── dataset.yaml
```

图片和标签必须同名：

```text
images/subject_sub-013_frame_000123.jpg
labels_yolo/subject_sub-013_frame_000123.txt
```

## 3. YOLO 标签格式

每一行表示一个框：

```text
class_id x_center y_center width height
```

所有坐标都归一化到 0–1，格式示例：

```text
0 0.312500 0.480000 0.180000 0.220000
0 0.688000 0.480000 0.180000 0.220000
```

其中 `0` 表示 `eye`。一张图有两只眼，就有两行；只有一只眼，就只有一行。

不要手工把像素坐标直接写进 YOLO 标签。标注工具导出时应自动完成归一化；如果自行转换，必须用原图宽度和高度换算。

## 4. 标注后的人工清单

建议另存一个 `annotations.csv`，便于审计。至少包含：

```text
image_id,subject,video,frame_idx,frame_type,n_eye_boxes,quality,annotator,review_status,notes
```

字段含义：

- `n_eye_boxes`：0、1 或 2；
- `frame_type`：clear、dark、overexposed、reflection、blink、closeup、mixed、no_eye；
- `quality`：high、medium、low；
- `review_status`：single_checked、double_checked、needs_fix；
- `notes`：记录遮挡、眼镜、裁切、假框等情况。

这个 CSV 不是 YOLO 训练输入本身，而是训练数据的来源和质量记录。

## 5. 离线标注工具要求

工具只需要满足三点：

1. 可以画矩形框；
2. 可以导出 YOLO 格式；
3. 不依赖在线账号或云端上传。

可以使用本地 CVAT、LabelImg 或其他支持 YOLO 导出的离线工具。不要把正式 NIR 原视频上传到在线标注平台。

如果工具只导出 Pascal VOC 或 COCO，也可以后续转换，但必须保留原始导出文件，不能只保留转换后的 txt。

## 6. 标注质量检查

每完成一批，必须检查：

- 图片和标签是否一一对应；
- 标签是否存在负坐标或大于 1 的坐标；
- 类别编号是否只有 0；
- 画框是否真的覆盖双眼；
- 是否把鼻梁阴影标成眼睛；
- 闭眼和反光帧是否按照同一规则标注；
- 同一被试相邻帧的框大小是否突然变化。

至少抽查 10% 图片，由第二个人复核；若只有一个人标注，也要第二次盲查并记录版本。

## 7. 和瞳孔人工复核的关系

眼框标注和瞳孔真值标注要分开保存：

```text
眼框标注：训练 YOLO，目标是“眼睛在哪里”
瞳孔标注：评价 PuReST/DeepVOG，目标是“瞳孔是否可见、边界在哪里”
```

同一张图可以同时有两套记录，但不能用眼框标签代替瞳孔椭圆标签。
