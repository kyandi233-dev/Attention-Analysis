# 08-16 NIR 算法封装与可移植说明

> 08-16（Asia/Shanghai）｜把 4 个 ROI 后端 + 4 个瞳孔算法全部封装成统一接口、自包含可移植包；本机不选最优，新设备跑完再选型。工程/迁移命令见根目录 `SETUP.md`，本文只记 NIR 领域视角的算法分工与决策。

## 1. 正式画面分型（7 被试实测，推翻"单被试全淘汰"）

| 类型 | 被试 | MediaPipe 检出率 | 判定 |
|---|---|---|---|
| 完整脸 | sub-013 | 91% | mediapipe 可用 |
| 完整脸 | sub-9504 | 68% | mediapipe 可用 |
| 双眼/鼻梁特写 | sub-011 / 012 / 016 | ≈0% | 需眼部专用 ROI |
| 混合 | sub-014 / 015 | 30–40% | 记录时段分布 |

**根因**：特写画面（30cm 仰拍只进双眼+鼻梁）里不存在完整人脸，"先找完整人脸再推眼"的 MediaPipe/YuNet/YOLO-face 必然失败——是输入域不匹配，不是调参问题。Codex 只看 sub-011 就判「全淘汰」以偏概全。

## 2. ROI 后端（4 个，统一 `.eyes(frame)` 接口）

| 后端 | 脚本 | 机制 | 适用 |
|---|---|---|---|
| mediapipe | `roi_mediapipe.py` | 478 点眼角仿射 | 完整脸 |
| yunet | `roi_yunet.py` | 人脸框+5点眼中心 | 完整脸 |
| yolo | `roi_yolo.py` | 人脸框比例估计 | 完整脸 |
| **faceparts** | `roi_faceparts.py` | **直接检测 eye bbox，不依赖全脸** | **特写（新候选）** |

faceparts（`yolo-face-parts-detector`）类别映射 `0=eye,1=nose,2=mouth,3=eyebrow`，单 eye 类不区分左右、按 x 排序分左右。**风险**：训练域为 RGB（Helen/Menpo2D/AFW 等），与 940nm NIR 有域差，须在正式特写实测检出率（conf/imgsz/nano-vs-small 网格），不能凭 README 效果。许可证 AGPL-3.0。

## 3. 瞳孔算法（4 个，输入 ROI 图 → 瞳孔/虹膜椭圆）

| 算法 | 环境 | 机制 | 备注 |
|---|---|---|---|
| PuReST | venv-pupil | 经典瞳孔椭圆 + 连续追踪 | 已有完整链路（`nir_sequence_detect.py`） |
| RITnet | 主环境 torch | 4 类语义分割（OpenEDS NIR 域） | `models/RITnet-master/infer_ritnet.py` |
| DeepVOG | 需 keras/tf | UNet(10×10) 分割 + 2D 椭圆（不做 3D gaze） | `scripts/deepvog_pupil.py`，需单独 venv |
| Iris | 主环境 mediapipe | iris 5 点→虹膜圆 | `scripts/iris_landmark.py`，**仅全脸适用，特写失败；且输出虹膜非瞳孔** |

## 4. 模型权重归集与自包含

全部权重已归集 v2 内（`models/`），`configs/formal.yaml` 的 `paths` 用相对路径 `models/...`（`config.path_value` 自动 resolve 到 v2 根）。唯一绝对路径是数据盘 `formal_data_root` 和两个解释器路径（迁移时改这 3 处）。

## 5. 统一入口

`scripts/run_all_backends.py --subject <sub> --roi-backends faceparts,mediapipe --pupil-algos PuReST,RITnet` 循环 ROI×瞳孔，产出同构对比供选型。瞳孔算法输出最小公共列（sample_id/algorithm/found/center/major/minor/angle/confidence），PuReST 保持 34 列既有契约。
