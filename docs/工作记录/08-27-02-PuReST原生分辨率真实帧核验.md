# PuReST 原生分辨率真实帧核验工作记录

> 08-27（Asia/Shanghai）｜状态：已完成有界探针；跨被试验证暂停，转 Issue #19 调研

## 背景

当前正式 NIR 原始视频为 1920×1080。既有 RITnet 主链使用 640×400 模型输入，并曾在 320×160 分析画布上计算瞳孔几何。为判断 PuRe/PuReST 能否直接利用原始眼区像素，需要在真实帧上核验裁剪、缩放和算法内部工作尺寸，不能仅依据文档或旧结果推断。

## 目标

1. 建立与官方 PyPupilEXT Windows wheel 匹配的独立 Python 3.10 环境；
2. 从 sub-031 原始 1920×1080 NIR 视频读取同一真实帧及 `eyes.csv` 中的正式眼区坐标；
3. 对比原生眼区、PyPupilEXT 默认基准、显式原生基准和旧 320×160 输入；
4. 输出检测器输入尺寸、源码可推导缩放比例、瞳孔椭圆、置信度、运行时间和 bounded overlay；
5. 明确区分“裁剪原始像素”与“resize 后降低空间分辨率”。

## 计划步骤

1. 核验 Git 状态、官方 wheel 版本与 SHA256；
2. 在 `D:\CondaEnvs\pypupilext310` 建立隔离环境，不修改现有 `nir-amd` 和 RGB 环境；
3. 使用 sub-031 block2 左眼真实帧进行四种输入方式的同帧测试；
4. 生成仓库外测试表、叠加图和运行元数据；
5. 核对输出并在本记录补充最终结果和后续决策。

## 风险

- PyPupilEXT 当前 Windows wheel 只支持 CPython 3.10；
- PuRe/PuReST 的 `baseSize`、ROI 重载和追踪状态存在特殊语义，不能只看返回椭圆判断是否经过缩小；
- 单帧结果只能回答像素链路和调用行为，不能单独证明整批数据的测量准确率；
- 测试产物必须留在仓库外，不覆盖正式输出。

## 校验标准

- 原始 AVI 帧确认为 1920×1080；
- 原生 ROI 的宽高与 `eyes.csv` 坐标差完全一致；
- 每种测试明确记录 detector input shape 和可推导的 scaling ratio；
- overlay 能映射回原始帧并落在正确眼别；
- 失败与异常显式记录，不以插值或静默 fallback 掩盖。

## 执行与核验结果

1. 已在 `D:\CondaEnvs\pypupilext310` 建立隔离的 Python 3.10.20 环境，安装仓库历史资产中的官方 PyPupilEXT 0.0.1 wheel、OpenCV 4.10.0.84、NumPy 1.26.4，以及用于候选对照的 Pupil Labs `pupil-detectors` 2.0.2。没有修改现有 `nir-amd` 环境。
2. sub-031 NIR 原视频已确认为 1920×1080、30 fps。目标帧 46988 左眼的 RITnet 补边 ROI 是 678×355 个源像素，YOLO 紧眼框约为 424×187 个源像素。裁剪本身保留 1:1 源像素；后续 resize 到 320×160 才降低空间采样。
3. 目标困难帧中，PuRe 在默认基准、显式原生基准、紧眼框和 320 尺寸等多种输入下均出现错误轮廓；原生紧眼框结果明显落在下眼睑。Pupil Labs 2D 在该帧返回未检测。以现有 RITnet 椭圆映射回源坐标作为 PuReST 局部种子，该帧也失败。
4. 在 frame 46900–47050 的 151 帧有界窗口中，Pupil Labs 2D 有 72/151 帧返回正置信度。可与 RITnet 同时比较的 50 帧中，中心差中位数约 7.80 个源像素，但主轴比例波动较大，中位约 1.26，P10–P90 约 0.76–2.57。该结果仅表示 agreement，不是 accuracy。PuRe 虽有 86/151 帧返回 valid 且正置信度，但可比较帧与 RITnet 中心差中位数约 138 像素，表明大量眼睑或边缘假检测。
5. PuReST 原图局部细化在该窗口 85 个可映射 RITnet 种子上为 0/85 成功。该负结果说明“离线”和“原生像素”不会自动使 PuReST 适配当前遮挡、强反光画面。
6. 同时刻 RGB 已核验为 1280×720。MediaPipe 关键点显示每眼横向仅约 32–33 个源像素，保留余量后的眼区约 66×37 和 64×38；样例还存在眼镜反光。两眼 Pupil Labs 2D 均未检测，PuRe 一眼失败、另一眼为镜片/眼区错误结构的低置信假检测。当前只支持把 RGB 作为头位、脸尺度和距离变化辅助，不支持把它作为精细瞳孔直径主测量。
