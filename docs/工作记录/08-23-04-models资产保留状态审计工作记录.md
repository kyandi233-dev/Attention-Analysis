## 一、审计目的

本轮回答：根目录 `models/` 中哪些内容属于当前正式分析，哪些只是历史候选，哪些可以在做好 provenance 后从 `main` 精简。

判断标准：

1. 当前正式 NIR pipeline 是否直接依赖；
2. 新设备正式运行是否必须包含；
3. 是否只是历史方法复现所需；
4. 是否可以通过工作记录、decisions、Git 历史 / 冻结历史版本和上游来源重新获得。

因此根 `models/` 不是当前正式分析的模型入口。

## 三、为什么 `datasets/` 和 `training/` 仍需要保留

`datasets/` 和 `training/` 虽然也是研究过程中形成的资产，但它们仍然构成当前正式模型的直接 provenance：

```text
datasets/
→ 固定训练/验证/测试划分
→ training/
→ YOLO best.pt
→ runtime 冻结副本
→ 正式 NIR 全量分析
```

因此它们属于“当前结果的可追溯来源”，不能与已经淘汰的 DeepVOG、YuNet、face-parts 等历史候选放在同一类处理。
