## 执行决策过程

> 用户：打开 `artifacts/gate1-review-preview/review.html` 没东西。

回答与落实：定位到 `render_review_html` 模板中 `.join('\n')` 的 `\n` 被 Python f-string 转成真实换行符，把 JS 字符串劈成两行导致整个 `<script>` 语法错误、页面空白。修复为 `.join('\\n')`，并把"盲标页 JS 无裸换行字符串"固化为契约检查与单元测试断言（防回归）。

> 用户：还是打不开。

回答与落实：进一步用 node（v24 可用）对生成的 `<script>` 做 `--check` 语法校验与实际运行测试，定位到第二处根因——JS 里 `export.onclick=...` 直接引用了 `id="export"` 的按钮，而 **`export` 是 JS 保留字**，在浏览器脚本里作为标识符是语法错误，导致整个 script 不执行、页面空白。同时 `localStorage.getItem/setItem` 在 `file://` 协议或某些浏览器沙箱下会抛 SecurityError，位于 `<script>` 顶层同样会导致空白。修复：`export.onclick` → `document.getElementById('export').onclick`；localStorage 读写包 try-catch；`replaceAll` → `replace(/"/g,'""')` 兼容旧浏览器。用 node + 禁用 localStorage 的 stub 实际运行验证：页面正常渲染、导出按钮正常。三项均固化为契约/测试断言（无裸换行、不用 export 保留字、localStorage 被 try 包裹）。

> 用户：现在的数据都是预实验的数据，管线搭建会考虑正式实验的结构，但现在验证分析还是沿用旧实验结构吗？
