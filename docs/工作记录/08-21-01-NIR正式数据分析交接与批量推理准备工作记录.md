## 总结

当前项目从 NIR 预实验 ROI 审计进入正式数据分析准备阶段。眼框检测模型正在 AMD RX 6750 GRE 12GB 电脑上使用 CPU 训练 100 epochs。训练结束后，计划视条件转移到 NVIDIA 电脑，处理一百多个约 25 分钟视频。

正式视频路线暂定为：

```text
OpenCV 读取视频
→ YOLO 周期性重新检测
→ tracking 更新中间帧眼睛 ROI
→ RITnet 处理 ROI
→ 连续性、可用性和失败状态 QC
→ NIR 指标与行为时间窗汇总
```

## 计划

1. 在训练电脑保留 `best.pt`、`last.pt`、`args.yaml`、`results.csv`、验证图、数据集 split 和完整环境信息。
2. 回珠海后在 NVIDIA 电脑验证模型加载、单帧 YOLO、单视频读取和输出字段。
3. 用短视频比较 YOLO-only 与 YOLO+tracking 的速度、ROI 漂移、重新检测恢复和出画处理。
4. 接入 RITnet，检查闭眼、无眼、遮挡、跟踪失败和瞳孔检测失败是否分别记录。
5. 通过短视频连续性和人工抽查后，才决定是否进行一百多个视频的全量运行。

## 执行决策过程

### 用户当前决策

- 北京已经收集一百多份正式数据。
- 2026-08-23 晚回珠海，之后开始正式分析准备。
- YOLO 已在 AMD 电脑上以 CPU 进行 100 epochs 训练。
- 正式处理采用 YOLO + tracking + RITnet；训练结束后可能转移到 NVIDIA 电脑批量推理。

### 需要保留的未冻结项

- 具体 YOLO 模型变体和训练覆盖批次，以训练结果文件为准。
- tracking 的具体实现、重检测间隔和失败重置条件，不能仅凭经验预设。
- RITnet 的输入尺寸、权重版本和质量门，需要用正式视频短片验证。
- 全量运行前必须保留失败、缺失、拒绝和可用状态，不能用插值掩盖算法失败。
