## 结果概览

### 数据（主队列 n=19，另敏感性 n=20）

- 25,920 试次（20 被试）、2,880 No-Go、600 探针；提取校验全绿。
- sub-015 完全无反应（144/144 误按、仅 2 次正确 Go）→ 排除；sub-025 RT 均值 751ms、sub-029 漏报 22.3% → 保留标记。

### 主效应（block B1→B3，n=19，Holm 校正）

| 指标 | B1→B3 Δ | Holm p | 方向 |
|---|---|---|---|
| 漏按率 | +0.019 | **0.007** | 上升（警戒衰退） |
| RT-CV | +0.116 | **0.021** | 上升（稳定性下降） |
| d′ | −0.29 | 0.18 | 方向性下降 |
| 误按率 | +0.002 | 1.00 | 无变化 |
| 反应标准 c | +0.13 | 0.17 | 略向保守 |
| RT 中位 | −16ms | 0.11 | 略加快 |

### 交互（block × 周期bin）

RT 中位与误按率的 block×bin 交互均不显著；但 RT 漂移的 block×cycle 交互显著（MixedLM interact_p=0.001）。

### 回归

- **block 内 RT 漂移**：B2 +1.30 ms/cycle（p<0.001）、B3 +0.91（p=0.003）、B1 +0.02（n.s.）。
- **错误前加速**：No-Go 前 lag−1 偏移差 −45ms、lag−2 −24ms（Holm p<0.002）。
- **GEE**：lag1 偏移对误按边际（p=0.083）；position_in_cycle 显著（p<0.001）。
- **探针→行为**：Q2 警觉度与探针后 RT 无显著关联（被试内）。

### 相关

- d′ × RT-CV：ρ=−0.89（p<1e-19）；d′ × RT 中位：ρ=+0.55。
- 跨 block 一致性（B1↔B3）：ρ 0.55–0.92，重测信度良好。

### 图表

20/20 张生成（`051-01..20`），报告内嵌并逐张附说明；报告 `001-正式SART行为分析报告.md`。
