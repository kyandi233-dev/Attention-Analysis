# Behavior｜行为分析

本目录统一保存行为模态的当前说明与正式 SART 分析资产。顶层只承担“行为模块入口”职责，不再把 `behavior` 与 `sart-formal` 作为两个并列文档模块。

## 当前入口

- `sart-formal/`：已经形成的正式 SART 行为分析计划、报告、图表与对应工作记录包。
- `014-正式实验修改建议报告.md` / `.pdf` 与 `plots/`：正式实验前形成的行为证据与修改建议，按历史研究语境保留。
- 行为分析代码仍以仓库实际代码目录和配置为准；本目录主要承担研究说明、结果报告与 provenance 导航。

## 目录原则

后续新增“当前方法”说明时，在 `030-behavior/` 顶层使用 `031-`、`032-`、`033-` 等文档编号；程序文件、配置文件和输出文件不因为文档排序而增加数字前缀。

历史报告及其配套图表不追溯改写。若正式方法发生变化，应新增当前说明或 decision record，而不是覆盖旧报告的历史语境。
