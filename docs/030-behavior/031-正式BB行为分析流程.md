# 031 正式 BB 行为分析流程

## 1. 适用范围

本文档描述 FocusWave v3.1.3 最终正式实验的行为分析流程。正式任务包含两个 B block，不沿用早期 v3.0 BBB 的三 block 推断结构。

```text
正式数据根目录
→ 发现编号 ≥31 的完整正式被试
→ 读取 B1 / B2 behavior CSV
→ schema 与跨被试完整性校验
→ trial-level 派生变量
→ block / cycle-bin / probe 指标
→ B2-B1 被试内统计
→ block 内时间趋势
→ 图表与 Markdown 报告
```

## 2. 被试发现

`configs/behavior_formal.yaml` 中 `include: []` 表示不写死被试名单，而是在配置的数据根目录中自动发现编号达到正式版本下限的被试。

一个被试只有在 B1、B2 行为文件都存在时才属于可分析集合。发现任何正式编号被试存在不完整 block 时，提取阶段直接报错，不静默跳过。

## 3. 输入文件

当前 reader 延续 FocusWave 行为文件命名契约：

```text
sub-XXX_/beh/
├── sub-XXX_Block1_B_beh.csv
└── sub-XXX_Block2_B_beh.csv
```

每个 CSV 必须满足当前 27 列行为 schema。若最终 v3.1.3 的实际 CSV schema 与此不同，应根据真实文件更新 reader，而不是向旧 BBB 格式强行兼容。

## 4. 当前与历史的关系

旧 v3.0 BBB 分析已整体归档到 `history-bbb-v3.0/`，完整可执行快照冻结在 `history/behavior-bbb-v3.0`。当前代码不继续支持 B3；如果以后确实需要重跑 BBB，直接从历史快照恢复。
