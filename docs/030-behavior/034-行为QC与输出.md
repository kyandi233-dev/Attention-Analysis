# 034 行为 QC 与输出

## 1. 结构 QC

提取阶段至少检查：每名被试是否同时具有 B1、B2；`trial_num` 是否缺失或重复；condition 是否为 B；commission/omission 与 Go/No-Go 是否一致；`response=1` 时是否缺失 RT；正式 cohort 中各被试同一 block 的 trial、No-Go、probe 数是否一致。

当前配置不从旧 BBB 继承“每 block 432 trial / 48 No-Go / 10 probe”等硬编码数量。正式 BB 的实际数量由真实数据首先确定；确认后如需冻结，再写入 current config。

## 2. RT QC

`<100 ms`、`<150 ms`、`>1000 ms`、`>1150 ms` 和 timestamp 不一致只标记，不自动删 trial。

## 4. 与 NIR 对齐

Behavior 与 NIR 都以 v3.1.3 的 B1/B2 为正式结构。后续跨模态分析应以 subject + block + trial/time 为对齐键。
