# 033 统计分析方法

## 1. 主要问题：B1 到 B2 是否变化

最终正式设计只有两个 B block，因此主要 block 推断不使用三水平 Friedman，也不再报告 B3-B1。

对每个主要行为指标建立被试内 B1/B2 配对表，报告 B1、B2 均值，B2−B1 平均差与 bootstrap 95% CI，配对 Wilcoxon、Cohen's dz，以及主指标族 Holm 校正。

## 2. Block 内时间趋势

使用 cycle-bin 描述 B1、B2 内部轨迹，并使用 trial-level MixedLM：`Go RT ~ block × cycle_num + (1 | subject)`。当数据满足平衡重复测量条件时，可补充 `block × bin` repeated-measures ANOVA。

## 3. No-Go 前兆

保留 No-Go 之前若干正确 Go RT 相对 block baseline 的变化，用于比较 commission 与正确抑制事件之前是否存在反应加速等前兆。

## 4. 探针关联

探针分析定位为辅助分析：`probe_vigilance` 与探针前 RT 使用 Spearman；名义 `probe_response` 类别与探针前 RT 使用 Kruskal-Wallis。

## 5. 与旧 BBB 的差异

旧分析中的 B1/B2/B3 Friedman、B3-B1 主对比、固定 sub-011~030 主队列以及基于 sub-015 的敏感性分析都属于 v3.0 BBB 历史，不进入当前正式分析。
