# 032 行为指标定义

当前指标以“被试 × block”为主要汇总层，同时保留 trial-level 与 block 内时间变化信息。

## 1. 正确 Go 反应

`go_rt_valid` 定义为正确 Go trial 的 RT。RT 不因过快或过慢被静默删除；阈值只形成 QC 标记。

主要速度与稳定性指标包括：Go RT median / mean / SD、RT-CV、ex-Gaussian μ/σ/τ，以及过快/过慢 RT 的 QC 比例。

## 2. 错误指标

- **commission rate**：No-Go trial 中误按比例；
- **omission rate**：Go trial 中漏按比例。

机会数始终随指标一起保存，避免只报告比例却丢失分母。

## 3. 信号检测指标

按 Go 正确反应作为 hit、No-Go commission 作为 false alarm，使用 loglinear 端点校正计算 d′、c 与 β。

## 4. 时间过程

每个 block 根据 `cycle_num` 划分 cycle bin，用于描述 B1、B2 各自从前段到后段的变化；trial-level RT drift 另使用 `cycle_num` 连续建模。

## 5. 探针

当前 runner 保留 `probe_response` 与 `probe_vigilance` 的原始编码，并计算探针之前若干正确 Go trial 的 RT 指标。

旧 v3.0 文档中的 Q1/Q2 文本标签暂不自动复制为 v3.1.3 的正式语义；在最终 FocusWave task source 被核验前，以原始数值编码作为 canonical data。
