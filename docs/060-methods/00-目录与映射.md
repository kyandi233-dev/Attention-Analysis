## 方法层与其他目录的边界

- `010-nir/`：记录 NIR 实际研究过程、训练/test 结果、历史候选路线和当前状态。
- `060-methods/`：解释可复用的方法机制、指标定义与参数语义。
- `070-architecture/`：解释模块如何连接、代码/数据/runtime 如何组织。
- `080-decisions/`：解释为什么选择或淘汰某个技术路线。
- `docs/工作记录/`：保留按日期发生的计划、执行与决策证据。

## 当前原则

1. 方法文档使用连续编号，后续新增从 `064` 顺延，不跳号。
2. 已能由代码、训练记录或 committed 工作记录核验的参数可以写入正文。
3. 08-22 portable runtime 的默认参数与正式 full-run 最终参数分开；未找到最终 `run_manifest.json` 前，不把默认值改称最终冻结值。
4. 方法说明解释“如何实现分析”；具体某轮实验的历史数值仍以对应 NIR 文档和工作记录为准。
