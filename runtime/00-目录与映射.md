# 00｜Runtime 目录与映射

`runtime/` 保存可复现运行环境、可运行分析包及其依赖快照。它不是正式分析结果输出目录。

## 当前正式 runtime

```text
nir-yolo-tracking-ritnet-v1/
```

这是当前已经用于正式全量分析的可运行 NIR pipeline。目录名称来源于较早开发阶段，名称中的 `tracking` 和 `v1` 不再准确描述当前正式模式；正式模式当前采用逐帧 YOLO，并保留 tracking 代码用于诊断/历史复现。

目录内包含：

- 正式运行配置 `config.yaml`
- 单被试/正式 batch 入口
- FocusWave v3.1.3 phase window 映射
- YOLO + RITnet 正式推理代码
- 当前正式模型权重副本
- requirements、测试与校验信息

## 其他 runtime 资产

| 路径 | 角色 |
|---|---|
| `nir-yolo-tracking-ritnet-v1.zip` | 较早阶段生成的可迁移压缩包快照 |
| `nir-yolo-tracking-ritnet-v1.zip.sha256` | 上述压缩包完整性校验 |
| `PyPupilEXT-0.0.1-cp310-cp310-win_amd64.whl` | PyPupilEXT 本地 wheel 依赖 |
| `requirements-main.txt` | 历史主环境依赖快照 |
| `requirements-pupil.txt` | 历史 pupil 环境依赖快照 |

## 命名整理

当前 unpacked 正式 runtime 后续建议从：

```text
nir-yolo-tracking-ritnet-v1/
```

重命名为：

```text
nir-formal/
```

原因是 runtime 名称应描述用途而不是内部算法组合。该重命名尚未执行；执行时需要同步当前有效配置和说明文档中的路径。历史工作记录以及旧 zip 快照继续保留原名称，不改写。

## 输出边界

正式分析结果应存放在独立分析输出位置，而不是作为长期产物堆在 `runtime/`。runtime 内部出现的 `outputs/` 仅属于运行配置/运行期路径，不改变“runtime = 可运行环境”的目录职责。
