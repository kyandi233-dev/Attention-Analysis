# artifacts｜历史证据产物索引

`artifacts/` 保存项目开发和方法选择过程中产生的**有限、可复现、具有审计价值的历史证据产物**，例如 Gate/QC、benchmark、ROI selection、sequence review、smoke test 等。

它不是正式全量分析输出目录。正式被试的全量中间结果与最终结果应继续保存在仓库外部，避免把大体量数据提交到 Git。

## 为什么保持扁平

当前 artifacts 数量有限，而且现有目录名称已经包含阶段和用途信息。继续额外拆成 `qc/`、`benchmark/`、`selection/` 等层级会：

- 增加历史路径变化；
- 破坏工作记录和脚本中的既有引用；
- 对当前规模没有明显检索收益。

因此当前约定是**有意保持扁平**，优先依靠清晰目录名和工作记录进行追溯。

## 保留原则

1. 历史 artifacts 不因正式路线已经确定而自动删除。
2. 不覆盖原始实验结果或复核证据。
3. 新生成的大体量正式输出默认不进入本目录。
4. 如果未来某类 artifacts 数量显著增加，再根据实际需要讨论分层，而不是预先重构。
5. 任何删除历史 artifact 的操作都需要用户明确同意。
