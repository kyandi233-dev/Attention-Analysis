# 00｜源码目录与映射

`src/attention_pipeline/` 是 Attention-Analysis 的项目级 Python 源码包。独立开发工具不放在 `src/`；当前辅助 MCP 已移动至根目录 `tools/`。

| 组件 | 用途 |
|---|---|
| `cli.py` | 项目 CLI 与审批/检查入口 |
| `config.py` | 配置加载和路径解析 |
| `contracts.py` | 数据/流程契约 |
| `protocol.py` / `validation.py` | 协议、被试、文件、时间轴与验证逻辑 |
| `io.py` / `metadata.py` | 通用 I/O 与元数据处理 |
| `behavior/` | 行为逐试次、block 与窗口证据逻辑 |
| `behavior_formal/` | 正式行为分析相关实现 |
| `nir/` | NIR ROI、检测评价、连续性、指标与相关核心逻辑 |

## 与 runtime 的边界

`src/attention_pipeline/` 保存项目级可复用源码；`runtime/` 保存已经用于正式运行的自包含环境/运行包。二者承担不同职责，不因仓库整理而强行合并。
