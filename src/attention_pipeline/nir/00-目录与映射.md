# 00｜NIR 源码目录与映射

> 2026-08-14（Asia/Shanghai）｜NIR 源码将端到端 ROI 失败、瞳孔可见性、检测失败与插值严格分轨；阶段4 新增六算法基准与参数调优。

| 文件 | 用途 |
|---|---|
| `roi.py` | 被试解剖眼别、320×160 固定眼角 ROI、仿射、三点椭圆、椭圆→多边形→IoU |
| `metrics.py` | 缺失 EAR 排除后的 PERCLOS 基础实现 |
| `review.py` | 264 原始帧设计、12眼预览、审批门1/代表性集构建、盲标与接触表 |
| `benchmark.py` | 阶段4 六算法单帧基准：几何门、光度门、三种率（端到端/算法层）、admission 判定、参数调优 sweep、报告 |
| `sequence.py` | 阶段5 连续序列：44×121 抽样、逐帧 MediaPipe→ROI→EAR/openness、门控校准（openness vs 528 人工可见性） |
| `sequence_eval.py` | 阶段5 评估：8 状态状态机、真实插值（≤200ms 线性填充标 is_interpolated）、连续指标、时间线图、报告 |
